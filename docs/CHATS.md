# Codex 聊天分工

本项目以 `D:\program\PD\dmr3` 为代码和文档根目录。聊天用于推进工作，仓库文件用于跨聊天交接；新聊天先读取与其任务相关的文档，不依赖其他聊天的完整历史。

| 聊天 | 负责内容 | 主要交接文件 |
| --- | --- | --- |
| 01 · Idea 讨论 | 问题、文献线索、可证伪假设和反例 | `docs/RESEARCH.md` |
| 02 · 方法与机制 | 数学定义、设计选择、机制预测和消融逻辑 | `docs/RESEARCH.md` |
| 03 · 代码与测试 | 按明确设计实现小范围改动，记录提交与验证 | 代码、测试、`docs/STATUS.md` |
| 04 · 服务器实验 | 固定提交和配置，启动、监控、续跑与记录 | `docs/EXPERIMENTS.md`、服务器运行目录 |
| 05 · 实验分析 | 汇总指标、检查异常、比较对照并说明证据边界 | `docs/EXPERIMENTS.md`、`analysis/` |

一次具体代码改动或正式实验可以另开短任务，标题写清任务、方法与运行编号；阶段聊天保留决策脉络。交接时给出文件路径、Git commit、运行编号、已验证事项和未解决问题。科研内容未定时，各聊天只建立边界，不替用户选择任务或方法。
