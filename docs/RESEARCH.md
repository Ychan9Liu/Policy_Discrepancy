### 参考文档中的方案（历史摘录，当前确认范围见规范）

以下定义摘自文档第 2、3 节。首版采用该参考定义已于 2026-10-08 确认；本仓库尚未实现或通过验证，正式配置与校准数值仍待确定。

- 对 categorical stochastic latent，分别取 posterior/prior 的 mode 并转成 one-hot：`zq_t = onehot(argmax q_t)`、`zp_t = onehot(argmax p_t)`；与相同 `h_t` 拼接。文档理由是避免 gate 额外引入采样噪声。
- 由同一个 actor 输出 `piq_t = pi(. | h_t, zq_t)` 与 `pip_t = pi(. | h_t, zp_t)`。连续控制参考定义为：

  `D_t = [KL(piq_t || pip_t) + KL(pip_t || piq_t)] / (2 * d_a)`。

  多 action head 先求 KL 总和，再按总动作维数归一化。Gaussian KL 包括均值和方差差异；它不是动作均值距离、value difference，也不是对 latent 边缘化后的策略 KL。
- 按参考文档的简化记号：

  `Kdyn_t = max(KL(sg(q_t) || p_t), tau)`；

  `Krep_t = max(KL(q_t || sg(p_t)), tau)`；

  `w_t = sg(1 / (1 + alpha * D_t))`；

  `LKL_t = Kdyn_t + lambda_rep * w_t * Krep_t`。

  迁移时须核对 baseline 实际外层系数、free-nats 粒度和 reduction；文档提及的 `lambda_rep` 通常为 0.1，不是本项目已确认配置。
- gate 在 free-nats 后、reduction 前作用：`w_t * max(KL, tau)`，不替换成 `max(w_t * KL, tau)`。文档理由是保留原有零梯度区域，并仅缩放活跃的 representation KL 梯度。
- actor 输入、Dt 和 gate 均停止梯度；不直接缩放 dynamics KL，不改变 actor 原有目标及其他 loss。文档意图是避免 gate 引入额外的 actor 优化路径，并维持清晰归因。“不直接改动 dynamics KL”不代表训练后 prior 参数或数值轨迹保持不变。
- 参考方案是单因素、可关闭的 overlay；`off`、`alpha=0`、`D_t=0` 应回退到原行为。能否达到参数、loss、梯度及随机数流的一致性，需要后续实现与测试，当前未验证。

| M1 方法有效性 | 相同预算与预先固定的评估协议下，Dt 相对 baseline 的主要任务指标有可重复增益 | 增益来自选择性，或表示获得控制充分性 |
| M2 选择信号有用（建议优先讨论） | 除 M1 外，相对合理匹配常数和有明确统计约束的打乱对照仍有增益；同时证明 gate 实际作用于活跃 rep 梯度 | gate 必然识别了任务因果信息，或排除了所有优化动态解释 |
| M3 选择性保护任务信息、抗干扰 | 在可控制任务相关因素与干扰因素的配对干预中，补充任务信息保留、行为及回报证据；测试预先留出的干扰变化 | 普遍干扰不变性、跨所有任务泛化或控制充分性证明 |

H1 的“改变当前策略”只是可计算的敏感性，不等于“有益于控制”。H2 是相对于指定匹配及打乱协议的命题。H3 是机制能够起作用的必要条件分析，不是收益充分条件。优先级在 2026-09-27 尚待答复，2026-10-08 已确定以 M2 为主。

### 数学与梯度边界（2026-09-27 本地化分析）

首版采用参考定义已于 2026-10-08 确认；以下分析用于解释其实现约束，当前数学与梯度规范见 `docs/METHOD_SPEC.md` 第 3、7 节，不再等待重新确认定义。

令 `q_t`、`p_t` 为 unimix 后的因子化 categorical 分布；以当前观察序列的共享 `h_t` 和两侧逐因子 mode 构造 actor 输入。先 sg 输入，再由同一个 actor 得到全连续 head 的条件 Normal 分布。

`D_t = sum_heads[ KL(piq_head || pip_head) + KL(pip_head || piq_head) ] / (2 * d_total)`。

每个 head 的 event 维只求和一次，结果为 `[B,T]`。`w_t=sg(1/(1+alpha*sg(D_t)))`，2026-09-27 提出的有限 `alpha>=0` 已写入当前规范；具体 alpha 数值仍未定。定义 `R_t=KL(q_t || sg(p_t))`、`F_t=max(R_t,tau)`，则默认配置的 KL 项为：

`L_KL = mean_BT[ max(KL(sg(q_t)||p_t),1) ] + 0.1 * mean_BT[w_t * max(R_t,1)]`。

上述两个 1 和 0.1 在实现中应读取原配置，不能硬编码。只读核对尚未运行数值或梯度测试。

对于 `R_t>tau`，rep 项对任意原有可达参数 theta 的贡献为 `beta_rep*w_t*grad_theta(R_t)/(B*T)`；对于 `R_t<tau`，为零。`R_t=tau` 是 maximum 的不可微边界，需保持 baseline/JAX 的原有约定，不能承诺该点严格零梯度。

必须分清三件事：

1. gate 分支本身对 actor、posterior、prior 和 history 的梯度为零。
2. 被缩放的 rep loss 仍通过 `q_t` 回传到 encoder、posterior 网络及其可达的递归 history；它对 history 的总梯度不要求为零。`sg(p_t)` 只切断 rep 项的 prior 目标分支。
3. dynamics KL 的表达式与其独立梯度在同参数、同 batch、同随机样本下保持不变；共享参数受到 rep 梯度影响后，下一步的 prior、dyn KL、actor 输入以及数据分布都可以变化。不能声称 prior 参数更新或长期 prior 学习轨迹保持不变。

逐时刻梯度乘 w 不等于整个 batch 的梯度范数乘 `mean(w)`，也不等于经过 AGC、自适应优化器和动量后的参数更新同比缩放。相关验收应落在可区分的原始 loss 梯度路径上。

### 机制边界及可区分诊断（助手分析／建议）

以下为 2026-09-27 的机制分析。2026-10-08 已确认 mode 漏检、早期不敏感、干扰误敏感、延迟线索四类局限的诊断义务，首版暂不叠加修复；具体诊断任务与干预仍待实验协议确定，当前实现日志要求见规范第 5 节。

- **mode 漏检：数学边界。** 所有因子的 posterior/prior mode 相同，则相同 history 下代表输入相同，Dt=0；即使概率质量和 latent KL 不同。不同 mode 也不保证 Dt>0，actor 可能忽略差异。建议同时统计逐因子与整向量 mode 不一致率、`P(D≈0 | raw_KL>tau)`；接近零的阈值待指定。这只能定位候选漏检，不能证明其中信息有用。
- **当前动作探针的边界：定义推论。** 某条线索对未来决策有价值，却不改变当前动作分布时，当前 Dt 可以很小。固定 h 的比较也不能穷尽信息沿未来 history 的影响。若论文要主张长期控制所需信息，须另加延迟线索诊断。
- **actor 早期不敏感：待验证假设。** 学习早期的低 Dt 可能来自 mode 相同、actor 尚未利用信息、posterior 已丢失信息，或确实没有相关信息；仅低 Dt 不能区分。需要分阶段联合看 mode 差异、策略均值/方差差异、活跃 KL 和任务线索行为。延迟开启 gate 不会自动恢复已丢失的信息，暂不作为默认修复。
- **干扰错误敏感：待验证风险。** 高 Dt 可能由背景、模型误差、策略方差变化或裁剪前的差异驱动。建议在相同物理状态与历史下，仅替换可控 nuisance，再比较 Dt、动作和后续任务结果；另做任务相关线索干预。任务相关状态变化往往应改变策略，不能要求所有干预下策略不变。
- **时间选择不等于因子选择：定义推论。** 标量 gate 同时减弱该时刻所有 stochastic 因子的 KL；即使 actor 的信号正确，也不自动获得去背景能力。
- **free-nats 无效区：数学边界。** 高 Dt 若只出现在 `R<tau` 的位置，会改变报告的加权 loss 常数，但不改变该 rep 项梯度。应报告活跃区权重和加权超额 KL，不能只看 `rep_after` 下降。

### 常数匹配与打乱的证据边界（助手建议，未选定协议）

本节保留 2026-09-27 的候选分析。当前已选定训练前校准并冻结的常数 c 和全局打乱，不采用在线 c(batch)/c(step)；只有常数匹配口径、校准数据及更强 M2 所需条件打乱的分层字段仍待定。当前实现语义以规范第 4 节为准。

以下所有均值首先定义在同一参数快照、同一批次的 rep 位置上；当前 baseline 为完整 `[B,T]`。记 `A=1[R>tau]`、`F=max(R,tau)`、`E=(R-tau)_+`。跨训练组数据和模型轨迹会分叉，因此这些同批次恒等式不能冒充全程匹配保证。

| 候选常数 | 匹配对象 | 保留的缺口 |
| --- | --- | --- |
| `c_w=mean(w)` | 平均系数 | 不匹配 `w` 与 KL 大小或活跃性的关联 |
| `c_A=sum(A*w)/sum(A)` | 活跃样本上的平均系数 | 不匹配活跃梯度大小、方向或不同样本的重要性；无活跃样本时应标记不可用 |
| `c_F=sum(w*F)/sum(F)` | 此批次 free-nats 后的 rep loss 数值 | 包含无梯度的 free-nats 常数，不能解释为压缩梯度匹配 |
| `c_E=sum(w*E)/sum(E)` | 此批次超过 free-nats 的加权 KL 数值 | 更接近活跃惩罚的标量诊断，但仍不是梯度向量或更新匹配；分母为零时不可校准 |

2026-09-27 的助手建议是以固定 `c_w` 作为基础对照，并用预先指定的校准数据检查活跃权重与超额 KL 的匹配缺口或增加常数档位。不能根据正式测试结果挑出最有利的常数。固定 c、预定 c(step)、自适应 c(batch) 是三种不同干预；当时具体形式待用户选择。2026-10-08 已选定训练前校准并冻结的固定 c，首版不采用 c(step)/c(batch)；是否用 `c_w` 校准及是否增加敏感性检查仍未定。

不存在一般的标量 c 能令 `sum(w_t*g_t)=c*sum(g_t)` 对任意逐样本梯度向量成立。即使匹配一个范数，也没有匹配方向或优化器历史。因此建议限制主张为“超出这些指定统一减弱方案的收益”，不声称完全排除所有压缩强度解释。

对打乱 gate 建议明确两个不同问题：

1. **全局有效位置打乱**：同一次更新内置换 `[B,T]` 的权重，保留本批次权重多重集合、均值及训练阶段，破坏与当前位置的对应。但会改变活跃位置权重、权重与 KL 大小的协方差、episode 位置和时间相关性。Dt 优于此对照只支持这种整体对应关系有用。
2. **条件打乱（更窄的诊断）**：在相同活跃状态、预定义 raw-KL 区间、边界类别等层内置换，减少活跃区和惩罚强度混杂。该对照刻意保留层间关联，只检验层内精细对应关系；不能再把它称为去除了全部选择信息。分层过细会失去可置换样本。

上述二者均应记录打乱前后 `active_weight_mean`、`mean(w*E)`、`cov(w,R)`、实际换位比例及单例层比例。保持时间相关的整段跨序列交换是另一种备选，检验的问题不同，未决定采用。打乱在本组当前 batch 上计算再置换；它保留的是本组本批次集合，不保证与独立 Dt 组的训练分布相同。打乱 RNG 应独立且可重放，避免消耗 baseline 采样随机流。当前不凭空新增 mask；未来若数据接口增加 padding，所有匹配、置换和统计须共享有效索引与原 reduction。

### alpha、任务、指标和可证伪判据（助手建议，待确认）

**alpha 校准候选协议**：在不改变训练目标的 logging-only baseline 中，预先固定任务、训练阶段窗口、校准 seed、分位数和目标权重；计算 `alpha=(1/w*-1)/D*` 后冻结，用独立评估检验。窗口应覆盖计划 gate 起作用的阶段，而非仅随机初始化。baseline 校准不能保证启用 gate 后 Dt 分布不漂移，所以需持续报告分阶段分布，但不自动在线改 alpha。

若中位数等选定分位数为零或近零，应报告零质量比例并判定当前校准规则退化；不要随意加 epsilon 生成极大 alpha。正值条件分位数或更高分位数属于需要预先规定的备选，且必须同时报告全体与活跃区分布。除了 D/w 的 median、p10、p90，至少联报 `rep_active_frac`、`active_weight_mean`、`mean(w*E)`；alpha、c 的调参信息与预算均需对照公平，不能利用测试集选值。

**任务选择标准**：先明确是 M1、M2 还是 M3。全连续动作最接近参考分布定义；视觉任务还需明确是否允许 proprio，避免视觉线索被其他观测绕过。本地存在 `dmc_proprio` 与 `dmc_vision` 预设（`configs.yaml:178`），这是代码适配线索，不是正式任务决定或环境可运行证据。对 M2/M3，最好有可配对控制的任务相关线索和 nuisance，必要时包含延迟线索来暴露当前动作探针边界。clean/训练干扰/未见干扰均需定义生成机制、强度、是否改变动力学，以及训练与评估划分，不能仅给条件名称。

**主要结果候选**：以环境交互步为横轴的预定义区间 return AUC，或末尾固定评估窗口均值，两者先选一个主指标，另一项为次要指标；相同交互预算外另报吞吐、耗时和内存。训练 seed 是主要独立重复单位，多个评估 episode 不能当作独立训练重复。固定评估动作规则、评估频率、环境随机性和配对方式；注意当前 `Agent.policy()` 即使收到 eval mode 仍调用 sample，不能默认它用动作均值。若用 DMC，本地构造函数尚未显式接收 seed，环境 seed 控制需单独审计，不可假定 config.seed 已控制全部随机性。

**可证伪或不支持的情形**：

- M1：预先定义的最小有意义增益为 delta，若主要指标差异的区间上界仍小于 delta，则不支持该任务/预算下有意义的收益；区间过宽是证据不足。delta、置信区间方法、seed 数及预算均待定。
- M2：与匹配常数或有效打乱对照相比，结果落入预先定义的等效范围，则不支持所检验的额外选择收益；“未显著”本身不能证明等效。若只胜过全局打乱、不能胜过活跃/KL 条件打乱，证据更符合粗粒度活跃性或 KL 强度分配，尚不足以支持更精细的任务信息选择。
- H1/M3：控制物理状态后，nuisance 引发高 Dt 和减弱压缩，伴随更差的未见干扰行为/回报，构成对“高 Dt 总能识别有用信息”的反例。单次相关性不证明因果保护；需配对干预和重复结果。
- H3：如果权重几乎为 1，或减弱都发生在 free-nats 非活跃区，则当前运行没有充分检验所提梯度机制，不能把零收益泛化为所有校准下无效；也不能把其他收益归因于该梯度路径。

1. **配置与接口**：明确 off、logging-only、Dt、constant、shuffle 的语义、alpha/c 合法范围和不支持动作分布的行为；不增加可训练参数。全连续多 head、标量及多维 action event 均有明确定义；离散/混合若未适配应显式报错，off 模式仍支持原 baseline 任务。
2. **初始化及回退**：固定同一环境、batch、carry、seed，与未改动 baseline 比较参数键/初值、模块状态、loss、全部参数梯度、一次 optimizer 更新及随机流。off、logging-only、alpha=0 都应覆盖；off/alpha=0 候选采用静态旁路。浮点容差应按 dtype/后端事前给定，不能以长程训练曲线逐位相同替代局部测试。
3. **代表输入和 KL**：共享 h、逐因子 argmax、特征拼接与 `[B,T]` 对齐；prior=posterior 或 mode 相同则 D=0、w=1；不同 mode 而 actor 相同也为零。解析 fixture 覆盖仅均值差、仅方差差、双向对称、多 head 总维数归一化；检查有限值和小数值负误差处理策略。
4. **梯度隔离**：gate 对 actor、两侧 logits 与 h 梯度为零；检验 rep 对 posterior 路径梯度保留，不能误把整个 rep loss detach。以人为固定的逐点权重验证活跃 rep 梯度逐点缩放、阈值以下零梯度、阈值处保持原约定；不能仅拿 batch 总梯度与 mean(w) 相乘比较。
5. **未改动分支**：同参数、输入和随机样本下，dyn loss/其独立梯度、actor/value/reconstruction/reward/continuation 原 loss 及梯度保持一致；总梯度差仅等于预期 rep 分支变化。不要把“未来 prior 轨迹不变”或“rep 对 h 总梯度为零”写进测试。
6. **reduction 和 replay**：scale 只乘一次，gate 在 free-nats 后和 mean 前；对 replay_context 开关、连续 chunk、reset、terminal 和不同 imag_last 验证 gate 始终匹配 world-model rep 的 T，不能误用 imagination 的 K 或 H。当前无 padding loss mask；未来才有的 mask 需求不可作为偷偷改变 baseline 的理由。
7. **shuffle/constant**：按最终选定协议验证权重集合、条件层、活跃权重、独立随机流、空层及退化分母处理；输出能说明保留及破坏哪些统计关系的日志。
8. **完整集成**：完整 agent 初始化、一次 loss、全参数梯度与 optimizer 状态均有限；测试至少包含连续 action fixture，不能只用默认离散 dummy。logging-only 不改训练状态，日志不更新 normalization 统计；性能开销单独计量。
