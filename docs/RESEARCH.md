### 参考文档中的方案（历史摘录，当前确认范围见规范）

以下定义摘自文档第 2、3 节。首版采用该参考定义已于 2026-10-08 确认；当时尚未实现。后续实现及小 fixture 验收见 `docs/CODE_PHASE1.md`、`docs/CODE_PHASE2.md`；已选择 alpha=20，固定 c 数值须按已确认 v1 匹配协议取得，完整正式配置仍待工程冻结。

- 对 categorical stochastic latent，分别取 posterior/prior 的 mode 并转成 one-hot：`zq_t = onehot(argmax q_t)`、`zp_t = onehot(argmax p_t)`；与相同 `h_t` 拼接。文档理由是避免 gate 额外引入采样噪声。
- 由同一个 actor 输出 `piq_t = pi(. | h_t, zq_t)` 与 `pip_t = pi(. | h_t, zp_t)`。连续控制参考定义为：

  `D_t = [KL(piq_t || pip_t) + KL(pip_t || piq_t)] / (2 * d_a)`。

  多 action head 先求 KL 总和，再按总动作维数归一化。Gaussian KL 包括均值和方差差异；它不是动作均值距离、value difference，也不是对 latent 边缘化后的策略 KL。
- 按参考文档的简化记号：

  `Kdyn_t = max(KL(sg(q_t) || p_t), tau)`；

  `Krep_t = max(KL(q_t || sg(p_t)), tau)`；

  `w_t = sg(1 / (1 + alpha * D_t))`；

  `LKL_t = Kdyn_t + lambda_rep * w_t * Krep_t`。

  迁移时须核对 baseline 实际外层系数、free-nats 粒度和 reduction；文档提及的 `lambda_rep` 通常为 0.1，不是本项目已确认配置。
- gate 在 free-nats 后、reduction 前作用：`w_t * max(KL, tau)`，不替换成 `max(w_t * KL, tau)`。文档理由是保留原有零梯度区域，并仅缩放活跃的 representation KL 梯度。
- actor 输入、Dt 和 gate 均停止梯度；不直接缩放 dynamics KL，不改变 actor 原有目标及其他 loss。文档意图是避免 gate 引入额外的 actor 优化路径，并维持清晰归因。“不直接改动 dynamics KL”不代表训练后 prior 参数或数值轨迹保持不变。
- 参考方案是单因素、可关闭的 overlay；`off`、`alpha=0`、`D_t=0` 应回退到原行为。能否达到参数、loss、梯度及随机数流的一致性，需要后续实现与测试，当前未验证。

### 科学主张应分层（2026-09-27 历史建议）

### 数学与梯度边界（2026-09-27 本地化分析）

首版采用参考定义已于 2026-10-08 确认；以下分析用于解释其实现约束，当前数学与梯度规范见 `docs/METHOD_SPEC.md` 第 3、7 节，不再等待重新确认定义。

令 `q_t`、`p_t` 为 unimix 后的因子化 categorical 分布；以当前观察序列的共享 `h_t` 和两侧逐因子 mode 构造 actor 输入。先 sg 输入，再由同一个 actor 得到全连续 head 的条件 Normal 分布。

`D_t = sum_heads[ KL(piq_head || pip_head) + KL(pip_head || piq_head) ] / (2 * d_total)`。

每个 head 的 event 维只求和一次，结果为 `[B,T]`。`w_t=sg(1/(1+alpha*sg(D_t)))`，2026-09-27 提出的有限 `alpha>=0` 已写入当前规范；具体 alpha 数值仍未定。定义 `R_t=KL(q_t || sg(p_t))`、`F_t=max(R_t,tau)`，则默认配置的 KL 项为：

`L_KL = mean_BT[ max(KL(sg(q_t)||p_t),1) ] + 0.1 * mean_BT[w_t * max(R_t,1)]`。

上述两个 1 和 0.1 在实现中应读取原配置，不能硬编码。只读核对尚未运行数值或梯度测试。

对于 `R_t>tau`，rep 项对任意原有可达参数 theta 的贡献为 `beta_rep*w_t*grad_theta(R_t)/(B*T)`；对于 `R_t<tau`，为零。`R_t=tau` 是 maximum 的不可微边界，需保持 baseline/JAX 的原有约定，不能承诺该点严格零梯度。

必须分清三件事：

1. gate 分支本身对 actor、posterior、prior 和 history 的梯度为零。
2. 被缩放的 rep loss 仍通过 `q_t` 回传到 encoder、posterior 网络及其可达的递归 history；它对 history 的总梯度不要求为零。`sg(p_t)` 只切断 rep 项的 prior 目标分支。
3. dynamics KL 的表达式与其独立梯度在同参数、同 batch、同随机样本下保持不变；共享参数受到 rep 梯度影响后，下一步的 prior、dyn KL、actor 输入以及数据分布都可以变化。不能声称 prior 参数更新或长期 prior 学习轨迹保持不变。

逐时刻梯度乘 w 不等于整个 batch 的梯度范数乘 `mean(w)`，也不等于经过 AGC、自适应优化器和动量后的参数更新同比缩放。相关验收应落在可区分的原始 loss 梯度路径上。

### 机制边界及可区分诊断（助手分析／建议）

以下为 2026-09-27 的机制分析。2026-10-08 已确认 mode 漏检、早期不敏感、干扰误敏感、延迟线索四类局限的诊断义务，首版暂不叠加修复；具体诊断任务与干预仍待实验协议确定，当前实现日志要求见规范第 5 节。

- **mode 漏检：数学边界。** 所有因子的 posterior/prior mode 相同，则相同 history 下代表输入相同，Dt=0；即使概率质量和 latent KL 不同。不同 mode 也不保证 Dt>0，actor 可能忽略差异。建议同时统计逐因子与整向量 mode 不一致率、`P(D≈0 | raw_KL>tau)`；接近零的阈值待指定。这只能定位候选漏检，不能证明其中信息有用。
- **当前动作探针的边界：定义推论。** 某条线索对未来决策有价值，却不改变当前动作分布时，当前 Dt 可以很小。固定 h 的比较也不能穷尽信息沿未来 history 的影响。若论文要主张长期控制所需信息，须另加延迟线索诊断。
- **actor 早期不敏感：待验证假设。** 学习早期的低 Dt 可能来自 mode 相同、actor 尚未利用信息、posterior 已丢失信息，或确实没有相关信息；仅低 Dt 不能区分。需要分阶段联合看 mode 差异、策略均值/方差差异、活跃 KL 和任务线索行为。延迟开启 gate 不会自动恢复已丢失的信息，暂不作为默认修复。
- **干扰错误敏感：待验证风险。** 高 Dt 可能由背景、模型误差、策略方差变化或裁剪前的差异驱动。建议在相同物理状态与历史下，仅替换可控 nuisance，再比较 Dt、动作和后续任务结果；另做任务相关线索干预。任务相关状态变化往往应改变策略，不能要求所有干预下策略不变。
- **时间选择不等于因子选择：定义推论。** 标量 gate 同时减弱该时刻所有 stochastic 因子的 KL；即使 actor 的信号正确，也不自动获得去背景能力。
- **free-nats 无效区：数学边界。** 高 Dt 若只出现在 `R<tau` 的位置，会改变报告的加权 loss 常数，但不改变该 rep 项梯度。应报告活跃区权重和加权超额 KL，不能只看 `rep_after` 下降。

### 常数匹配与打乱的证据边界（助手建议，未选定协议）

本节保留 2026-09-27 的候选分析。当前已选定训练前校准并冻结的常数 c 和全局打乱，不采用在线 c(batch)/c(step)；只有常数匹配口径、校准数据及更强 M2 所需条件打乱的分层字段仍待定。当前实现语义以规范第 4 节为准。

该段“匹配口径、校准数据待定”为 v1 确认前状态。现已选定本任务正式 logging-only baseline 的半开窗口与活跃位置统计和/计数；下表备选匹配方式不进入 v1，更强 M2 的条件分层仍属后续工作。

以下所有均值首先定义在同一参数快照、同一批次的 rep 位置上；当前 baseline 为完整 `[B,T]`。记 `A=1[R>tau]`、`F=max(R,tau)`、`E=(R-tau)_+`。跨训练组数据和模型轨迹会分叉，因此这些同批次恒等式不能冒充全程匹配保证。

| 候选常数 | 匹配对象 | 保留的缺口 |
| --- | --- | --- |
| `c_w=mean(w)` | 平均系数 | 不匹配 `w` 与 KL 大小或活跃性的关联 |
| `c_A=sum(A*w)/sum(A)` | 活跃样本上的平均系数 | 不匹配活跃梯度大小、方向或不同样本的重要性；无活跃样本时应标记不可用 |
| `c_F=sum(w*F)/sum(F)` | 此批次 free-nats 后的 rep loss 数值 | 包含无梯度的 free-nats 常数，不能解释为压缩梯度匹配 |
| `c_E=sum(w*E)/sum(E)` | 此批次超过 free-nats 的加权 KL 数值 | 更接近活跃惩罚的标量诊断，但仍不是梯度向量或更新匹配；分母为零时不可校准 |

2026-09-27 的助手建议是以固定 `c_w` 作为基础对照，并用预先指定的校准数据检查活跃权重与超额 KL 的匹配缺口或增加常数档位。不能根据正式测试结果挑出最有利的常数。固定 c、预定 c(step)、自适应 c(batch) 是三种不同干预；当时具体形式待用户选择。2026-10-08 已选定训练前校准并冻结的固定 c，首版不采用 c(step)/c(batch)；是否用 `c_w` 校准及是否增加敏感性检查仍未定。

不存在一般的标量 c 能令 `sum(w_t*g_t)=c*sum(g_t)` 对任意逐样本梯度向量成立。即使匹配一个范数，也没有匹配方向或优化器历史。因此建议限制主张为“超出这些指定统一减弱方案的收益”，不声称完全排除所有压缩强度解释。

对打乱 gate 建议明确两个不同问题：

1. **全局有效位置打乱**：同一次更新内置换 `[B,T]` 的权重，保留本批次权重多重集合、均值及训练阶段，破坏与当前位置的对应。但会改变活跃位置权重、权重与 KL 大小的协方差、episode 位置和时间相关性。Dt 优于此对照只支持这种整体对应关系有用。
2. **条件打乱（更窄的诊断）**：在相同活跃状态、预定义 raw-KL 区间、边界类别等层内置换，减少活跃区和惩罚强度混杂。该对照刻意保留层间关联，只检验层内精细对应关系；不能再把它称为去除了全部选择信息。分层过细会失去可置换样本。

上述二者均应记录打乱前后 `active_weight_mean`、`mean(w*E)`、`cov(w,R)`、实际换位比例及单例层比例。保持时间相关的整段跨序列交换是另一种备选，检验的问题不同，未决定采用。打乱在本组当前 batch 上计算再置换；它保留的是本组本批次集合，不保证与独立 Dt 组的训练分布相同。打乱 RNG 应独立且可重放，避免消耗 baseline 采样随机流。当前不凭空新增 mask；未来若数据接口增加 padding，所有匹配、置换和统计须共享有效索引与原 reduction。

### alpha、任务、指标和可证伪判据（助手建议，待确认）

本节保留 2026-09-27 历史候选。alpha 反算和独立校准 seed 的建议不适用于当前 v1；已固定 alpha=20、size50m、单训练 seed0，已确认匹配窗口只用于 c。此处当时的环境 seed 源码事实也已由后续适配与审计更新，当前状态见文末及 `docs/EXPERIMENTS.md`。

**alpha 校准候选协议**：在不改变训练目标的 logging-only baseline 中，预先固定任务、训练阶段窗口、校准 seed、分位数和目标权重；计算 `alpha=(1/w*-1)/D*` 后冻结，用独立评估检验。窗口应覆盖计划 gate 起作用的阶段，而非仅随机初始化。baseline 校准不能保证启用 gate 后 Dt 分布不漂移，所以需持续报告分阶段分布，但不自动在线改 alpha。

若中位数等选定分位数为零或近零，应报告零质量比例并判定当前校准规则退化；不要随意加 epsilon 生成极大 alpha。正值条件分位数或更高分位数属于需要预先规定的备选，且必须同时报告全体与活跃区分布。除了 D/w 的 median、p10、p90，至少联报 `rep_active_frac`、`active_weight_mean`、`mean(w*E)`；alpha、c 的调参信息与预算均需对照公平，不能利用测试集选值。

**任务选择标准**：先明确是 M1、M2 还是 M3。全连续动作最接近参考分布定义；视觉任务还需明确是否允许 proprio，避免视觉线索被其他观测绕过。本地存在 `dmc_proprio` 与 `dmc_vision` 预设（`configs.yaml:178`），这是代码适配线索，不是正式任务决定或环境可运行证据。对 M2/M3，最好有可配对控制的任务相关线索和 nuisance，必要时包含延迟线索来暴露当前动作探针边界。clean/训练干扰/未见干扰均需定义生成机制、强度、是否改变动力学，以及训练与评估划分，不能仅给条件名称。

**主要结果候选**：以环境交互步为横轴的预定义区间 return AUC，或末尾固定评估窗口均值，两者先选一个主指标，另一项为次要指标；相同交互预算外另报吞吐、耗时和内存。训练 seed 是主要独立重复单位，多个评估 episode 不能当作独立训练重复。固定评估动作规则、评估频率、环境随机性和配对方式；注意当前 `Agent.policy()` 即使收到 eval mode 仍调用 sample，不能默认它用动作均值。若用 DMC，本地构造函数尚未显式接收 seed，环境 seed 控制需单独审计，不可假定 config.seed 已控制全部随机性。

**可证伪或不支持的情形**：

- M1：预先定义的最小有意义增益为 delta，若主要指标差异的区间上界仍小于 delta，则不支持该任务/预算下有意义的收益；区间过宽是证据不足。delta、置信区间方法、seed 数及预算均待定。
- M2：与匹配常数或有效打乱对照相比，结果落入预先定义的等效范围，则不支持所检验的额外选择收益；“未显著”本身不能证明等效。若只胜过全局打乱、不能胜过活跃/KL 条件打乱，证据更符合粗粒度活跃性或 KL 强度分配，尚不足以支持更精细的任务信息选择。
- H1/M3：控制物理状态后，nuisance 引发高 Dt 和减弱压缩，伴随更差的未见干扰行为/回报，构成对“高 Dt 总能识别有用信息”的反例。单次相关性不证明因果保护；需配对干预和重复结果。
- H3：如果权重几乎为 1，或减弱都发生在 free-nats 非活跃区，则当前运行没有充分检验所提梯度机制，不能把零收益泛化为所有校准下无效；也不能把其他收益归因于该梯度路径。

### DL-1 研究问题与分析框架

**新增研究问题（候选，未替换 M2）**：在保留原 Dt 定义的条件下，以真实后续任务标签作为保护许可，能否减少缺乏任务预测支持的高 Dt 保护，同时保留有支持的有限保护；其收益是否超过单纯调整压缩强度？

区分四层：观测造成的状态分布更新；当前 actor 的响应及测量可靠性；信息对未来任务结果的价值；减弱 representation KL 的实际梯度作用。raw latent KL 主要描述第一层，Dt 主要描述第二层，二者不能自动回答第三、四层。

还要区分“何时保护”与“保护哪些信息”。逐时刻标量权重只改变该时刻全部 stochastic 因子的压缩强度，不能分离同一 latent 中的关键因素和干扰。

| 高 Dt 的可能成因 | 理想处理 | DtLatch 覆盖条件／失败边界 |
| --- | --- | --- |
| 当前观测包含改变正确动作的关键信息 | 适当保护 posterior | 若改善同一记录动作下的下一步奖励预测，有机会保留保护；不证明动作切换有益。 |
| prior 学习不足或预测偏差，posterior 修正估计 | 可能应保护，并继续训练 prior | 部分覆盖；不能区分关键偏差与一般模型失配。 |
| 随机但真实的重要事件，例如接触或外力 | 不能仅因不可预测而压掉 | 短期结果可预测时部分覆盖；真实高随机性也可能使分数低。 |
| actor 对背景／无关细节错误敏感 | 不应仅凭策略改变保护 | 若无奖励预测支持，可能减少保护；奖励伪相关会破坏该区分。 |
| posterior 被噪声、遮挡或分布外输入误导 | 通常不应保护错误更新 | 若预测也变差，可能减少保护；模型共同错误仍会误保护。 |
| 小方差或 KL 尺度放大，执行控制后果差别小 | 不把分布尺度当任务价值 | 无预测支持时可能抑制；不修复裁剪前 Gaussian Dt 的测量问题。 |
| categorical mode 跳变／代表状态误差 | 怀疑代表估计，再诊断 | 无法可靠解决；actor 与 reward head 可共同响应同一次 mode 跳变。 |
| 动作不同但价值相同，或变化方向错误 | 需要动作收益依据 | 候选没有动作收益反事实，不保证识别。 |
| 关键信息与干扰同时存在 | 只保留关键部分 | 不覆盖逐因子分离，标量 gate 会一起保护。 |
| 延迟线索或当前不影响下一步奖励的信息 | 保留长期决策信息 | H=1 系统漏检；不能把 e=0 解释为无用。 |
| 早期 actor 尚未利用关键信息 | 即使 Dt 低也可能需要保护 | 保留 Dt 条件后仍漏检；初始 reward head 尚未成熟也是边界。 |

以上不是实测分类或频率结论；不能按类别数量宣称覆盖多数样本。不可预测／不可控也不等于干扰，风向或交通信号可能是必要信息。

**raw KL 的候选价值与可辨识边界（本次推导）**。令 `K=KL(q(z|h,o)||p(z|h))`：高 D、高 K 表示状态更新与 actor 响应均大，但任务关键更新和噪声都可以如此；高 D、低 K 可能是 mode 跳变或小方差，也可能是真实决策边界敏感；低 D、高 K 可能是早期不敏感或延迟信息；低 D、低 K 不证明估计充分。

固定 q、p、actor，只改变真实动作奖励，就能使同一 D/K 对应有益、无益或有害的动作改变。因此仅凭 D/K 无法辨识任务收益。固定 h，令 `qbar(z|h)=E_o q(z|h,o)`，有：

```text
E_o KL(q(z|h,o) || p(z|h))
  = I_q(Z;O | h) + KL(qbar(z|h) || p(z|h))
```

这不是单样本互信息，更不是任务价值或 posterior 真实性。建议保留 raw KL 作诊断和梯度活跃性指标，不优先将它作为保护许可；D/K 在小 K 时还会放大数值问题。

**Dt 测量边界（本次推导）**。若比较完整边缘动作分布 `Pi_q=E_q pi(.|h,z)` 与 `Pi_p`，数据处理不等式给出 `KL(Pi_q||Pi_p)<=KL(q||p)`；mode Dt 不满足该界。接近等概率的两个类别可使 K 趋零、mode 不同而 D 保持非零；mode 相同又可漏掉其他分布变化。独立采样 q/p latent 后平均条件策略 KL，不是混合策略 KL，q=p 时仍可为正；将 soft probabilities 直接送 actor 也可能偏离其 one-hot 训练支持。

### DL-4 DtLatch 候选数学定义

b,t 是 replay context 处理后的 loss 位置。沿用标准 categorical RSSM/unimix 与原 actor，显式 detach 共享 h、q/p logits 和逐因子 one-hot mode。原训练 sampled latent 不改为 mode。

从同一 h_t、不同 z_t^j 出发，以同一实际记录动作做一步 open-loop 预测，不吸收未来观测：

```text
z_t^q = sg(mode(q_t)); z_t^p = sg(mode(p_t))
a_t = prevact[:, t+1]                         # 原 context 处理后的动作对齐
h_{t+1}^j = core(h_t, z_t^j, DictConcat(a_t))
z_{t+1}^j = mode(prior(h_{t+1}^j))             # j in {q,p}
P_t^j = reward_head(concat(h_{t+1}^j, flatten(z_{t+1}^j))).probs
```

两路径复用相同模块与 baseline 特征／action normalization，不复用正常未来 repfeat/h；正常未来状态已吸收未来观察，不能用作该比较。

令 y_t 为现行 reward `TwoHot.loss(r_{t+1})` 的准确 target 编码，用自然对数：

```text
ell_j = CE(y_t, P_t^j) = -sum_k y_tk * log P_tk^j
H_y = -sum_k y_tk * log y_tk
d_j = ell_j - H_y = KL(y_t || P_t^j) >= 0
u_j = exp(-d_j) in [0,1]
e_t = max(u_q-u_p, 0) in [0,1]
```

u 是标签兼容度，不是校准真实性概率；y 是 TwoHot 标签，不是环境真实 reward 分布。比只用正 loss gap 多一个绝对拟合约束：两者都很差时 u 均小，保护许可较弱；代价是更保守并可能漏掉真实随机事件。

当前 reward head 为 `symexp_twohot`：在非均匀的原 reward 尺度 bins 上线性插值，默认没有先 symlog(r) 再用等距 bins。必须复用实际 bins、squash、clip/equal 规则和稳定 log-softmax；范围外 target 的边界编码及发生数需记录，不能手写另一个标签定义。

```text
m_t = 1[t+1<T] * (1-is_last[t]) * (1-is_first[t+1])
w_D = 1/(1+alpha*D_t)
f_D = 1-w_D
v_t = sg(1 - m_t*rho*e_t*f_D)
```

下一步 terminal 端点 reward 可有效，禁止跨 reset／chunk 尾部。m 只是保护许可，不是新的 rep mask。理论范围为 `0<=rho<=1`、`alpha>=0`、`D>=0`，于是 `1-rho<=v<=1`。m=0、e=0 或 D=0 均 v=1；同参数／样本下 v 不小于原 w_D。

**助手建议的首轮规格**：H=1、reward-only、alpha=20、rho=0.5。alpha=20 在 v1 已确认，但沿用到本扩展仍是建议；rho=0.5 仅给固定参数下 rep 局部梯度的缩放下界，无经验最优依据，也不限制长期性能损失。暂不加 continuation：当前没有其额外辨别证据，而且其初始化不具备 reward head 两侧严格一致的性质。

```text
Rdyn = KL(sg(q)||p); Rrep = KL(q||sg(p))
L_KL = beta_dyn * mean_BT(baseline_free_nats(Rdyn))
     + beta_rep * mean_BT(v * baseline_free_nats(Rrep))
```

权重在原 free-nats 后、完整原 mean 前作用；不改阈值、分母、其他 loss 或 scale。Rrep>tau 时该点 rep 梯度按 v 缩放；Rrep<tau 时本来为零；等于阈值保留 baseline/JAX 约定。该局部结论不等于总 optimizer 更新或长期轨迹被同比缩放。

### DL-5 待批准的实现接口与退化规则

实现前由 02 确认科学语义；03 依据批准规范决定配置字段、数值容差及接口组织。这一节不是当前实现授权。

- 接入 `dreamerv3/agent.py` 现有 `rep_probe.overlay` 附近：正常参数创建后、总 loss reduction 前。复用已有 q/p mode、D 和 raw rep KL，避免重复 actor 前向。
- 输入：共享 h、q/p mode、context 后 prevact、reward、is_first/is_last、raw rep KL 及原 rep loss，保留 `[B,T]` 对齐。输出：m/e/v、两侧 loss/compatibility、有符号 gap、有效性和诊断计数；不新增训练状态或可训练参数。
- 将起点展平为 `[B*(T-1),S,C]` 等，再还原形状。当前 `_core` 的 flatten 假定 batch 首维，不能直接送 `[B,T,S,C]`。
- 用确定性 `_core -> _prior -> _dist.pred`，不能直接调用仍消耗 `nj.seed()` 的 `RSSM.imagine`。两路径可 stack 为 2N batch，无新 baseline RNG 消耗或 normalization update。
- 完整 probe 输出与最终 v 均 stop-gradient。仅 detach 输入不足以阻断共享 head 参数经 gate 反传；OneHot straight-through 也不能替代显式 detach。
- 正常 reward/dyn/actor/value/decoder 的既有梯度保留。不得声称 rep 对共享 history 或 dynamics 参数的全部梯度为零。
- 当前 reward logits outscale=0，初始化两侧 uniform，因此 e=0，自然从 baseline 保护力度开始；这不是后续早期可靠性保证。
- off、alpha=0、rho=0 静态旁路；logging-only 可算诊断但实际权重为1。保留参数键/初值、原随机流及 optimizer/normalization 状态。
- T<2、chunk 尾部或跨 reset：合法不可用，e 置0、v=1，单列 count；不能回退成原 Dt 保护。完整校准有效集合为空则比较未成立。
- score 与权重按 float32 稳定计算，0*log(0) 按熵定义处理；f 用 1-w_D 避免 Inf/Inf。微负 d 仅按事前声明浮点容差归零，明显负值／有效位置非有限值报错并停止相关运行，不静默伪造信号。exp 下溢到0可表示无支持。

额外前向成本估算：原 Dt 为 `2BT*C_actor`；本候选在其上增加约 `2B(T-1)*(C_dynamics+C_reward)`。没有新增反向 probe 梯度，但编译／中间 buffer／显存和吞吐须实测；不能把该算式当墙钟或 GPU 开销结论。

### DL-6 最小扩展验证设计（助手建议，未批准）

以下扩展不替代 v1 的四组、c 规则、seed0、预算或运行授权，也不往正在执行的作业追加模块。新任务、干扰、数据收集、配置与资源须另行批准。

| 组 | rep 权重 | 主要比较目的 |
| --- | --- | --- |
| B：baseline | 1 | 原模型参照。 |
| D：原 Dt | w_D | 原方案参照。 |
| N：DtLatch | 1-m*rho*e*f_D | 待验证候选。 |
| S：校准强度 Dt | 1-m*kappa*f_D | 控制保护上限／Dt形状／校准平均释放强度，检查仅调整压缩力度的解释。 |
| P：条件置换新权重 | 在冻结分层内置换本组当前 batch 的完整 v | 检查更细样本对应关系，不从另一训练组取权重。 |

在**另行批准的扩展校准数据／窗口**上，令 `A=1[Rrep>tau]`、`E=(Rrep-tau)+`，冻结：

```text
kappa = rho * sum(m*A*E*e*f_D) / sum(m*A*E*f_D)
```

同一个 m 必须进入校准和 S 权重。分母正时 `0<=kappa<=rho`；分母零／非有限为未校准，停止相应比较，不填默认值；分子零可冻结 kappa=0 并报告校准无释放。这只匹配校准窗口加权超额 KL 释放量，不匹配全程梯度、更新或组间数据分布；不是 v1 的 c 匹配。

条件置换至少按 m、free-nats 活跃状态、事前冻结的 D/raw-KL bins 分层，m=0 保持1；跨 shard 范围必须明确。保留每层权重集合及活跃平均权重，不声称精确保留 weighted excess 或全部 D/K 关系。对每层可记录：

```text
|sum_i (v_perm_i-v_i)*E_i|
  <= (E_max-E_min)/2 * sum_i |v_perm_i-v_i|
```

无界顶部 bin 用本次实际 min/max 作诊断界，不当预先全局界。报告 singleton、换位比例、移动的释放量、置换前后 weighted excess；换位过少则机制检验不充分。

扩展五组可均执行相同 detached H1 前向，B/D 丢弃新许可，只按各组定义训练，从而控制额外模型调用；记录校准、调参、实际墙钟／吞吐，匹配前向数不等于精确同耗时。冻结 alpha/rho/窗口/bins 与各组调参预算，不按正式 return 追选。

验收分四层，不相互替代：

1. **工程符合性**：动作／reward 对齐、无未来观测、TwoHot 编码、mask/terminal、shape、梯度、free-nats/reduction、初始化/RNG与关闭等价性。fixture 只能验这些性质。
2. **信号辨别**：独立 episode／留出数据，使用有明确语义依据的关键线索与合法 nuisance 干预；联报 ell_p-ell_q、u_q-u_p、e、D/K、预测拟合、释放量和误保护。不是所有 crop/遮挡都语义保持；任务干预方案须确认。检验训练背景与留出背景，避免只看 replay 拟合。
3. **压缩作用**：记录活跃 rep 比例、v 的分布、weighted excess/释放量、按阶段/D/K分层统计和 rep 梯度贡献。只在零梯度区起作用或有效集合无变化时，机制未充分检验；不要据此宣布科学命题被否定。
4. **真实性能**：建议沿用原始 return AUC 与固定末段定义，但扩展任务/seed/预算/判据需另定。训练seed是重复单位，评估episode不是；单seed仅描述，clean结果不证明抗干扰。保留逐任务结果与成本，不只展示总体均值。

支持预测：独立诊断中关键更新比无关变化获得更高许可；活跃压缩按预期变化；新方案的主要性能优势还超过 S/P 的相关解释。若只优于 D、与 S 相当，最多支持“原保护过强”，不支持新任务选择机制；有效置换后收益保留也不支持精细对应价值。若 DL-H1 区分消失或反向，撤回代理辨别主张。具体有意义增益／等效范围／区间与停止判据在批准扩展前冻结，不能借此改写 v1 的单seed、不设阈值决定。

五组不能证明 Dt 相比 reward-only 有额外价值。只有独立诊断或作用不足证据触发时，再申请该对照；不机械增加第六组，也不预称两信号必要。

### DL-10 r1真实证据与必要下一诊断（2026-10-10）

**已验证事实**：同一baseline seed0的300k/1m阶段各24 blind episode×32位置。原H10平均收益正例21/4点、cuecost26/7点，未达128位置/8 episode覆盖；活跃rep位置768/760点，超额KL释放0.12944%/0.22305%，原1%幅度判据未满足。P释放偏差11.883%/62.730%使对应关系对照不充分。背景平均新增保护满足上界，但存在单点大幅误保护。1m C AUROC约.971只有4个正例且第二信号增量区间跨0，不能写成辨别成立。两个阶段不是独立训练seed复现。

**工作假设与反例**：多数q/p H1预测接近，可能是先验已足够、actor未利用新增信息、奖励局部性或当前行为动作掩盖差异；目前不能区分。独立复算未发现实质数值错误，典型q兼容度接近1，绝对exp抑制不是普遍原因。去抑制会放大部分低兼容、真实收益不好的尾部，因此直接更换relative margin或提高alpha/rho没有充分依据。灰body保留姿态轮廓，也使低cuecost不能单独支持“线索不重要”。

**授权内Agent决定**：先做有上限的新H100机会诊断，而不先放大gate。新seed20261012，固定同两stage，各32 episode（8/24）×16预定位置；真实首q/p动作后99个共同记录动作，主标签累计收益≥.1、负例≤0，外观剥夺成本与其交集独立报告。H1/10/50只描述；这是新的外部研究对象，不是放宽r1验收。原H1 gate/alpha20/rho.5不变，所有诊断结果均不能直接授权训练。方案、必要性、反例、停止规则、预算见DL_OPPORTUNITY。

**尚未采用建议**：共同随机数与概率混合、真正策略边际差异、proper log-score差或有界评分、多步预测、真实关键状态/固定遮挡诊断，见 [DL_REVISIONS.md](DL_REVISIONS.md)。这些不是方法结论。选择何种修订取决于机会、误差和增量证据；仍未形成可正式实验方法，继续当前已授权任务。
