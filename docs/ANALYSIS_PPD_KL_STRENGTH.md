# PPD-KL没有明显优势：是否因为参数太小？

日期：2026-11-03。05基于已有seed0原始return与门控复算结果解释；排除acrobot，不新增训练或参数变更。**现有证据不支持把没有优势统一归因为alpha太小；也没有证明alpha20已经最优。**

## 参数含义与实际作用

当前冻结alpha=20，位置权重`w=stop_gradient(1/(1+alpha*D))`。alpha越大，w越小，对rep KL的减弱越强；它不是直接增加奖励或增强策略学习。rep外层系数0.1则是另一参数，调大该系数会加强rep约束，方向与调大alpha不同。

D衡量当前actor对后验/先验mode两种潜表示的动作分布差异；没有直接使用任务价值标签。因此，同一个alpha在不同任务/阶段的实际作用不同，D大也不能直接解释为对应位置对长期return更重要。不能用`1/(1+alpha*平均D)`代替平均权重，因该函数非线性且实际作用还受free-nats活跃集合影响。

gate乘在原free-nats之后、reduction之前。raw rep KL低于free-nats的位置原有rep局部梯度为零，改变该位置权重不会产生这条路径的梯度。活跃位置的权重、活跃比例和超额KL减弱要联合观察；平均权重或loss减弱不等于最终参数梯度范数变化。

来源：当前`dreamerv3/rep_probe.py`及`docs/METHOD_SPEC.md`定义；实际冻结值与训练结果见`docs/ANALYSIS_DMC15_V1.md`。本报告没有改写冻结口径。

## 用已有结果检验“作用太弱”解释

以下为新增15任务seed0中的示例。AUC使用未平滑的21点原始return梯形积分/100万；末段为80万至100万五点均值。Δ为PPD-KL减baseline。超额KL减弱是按成功更新累计的`excess_reduction/(weighted_excess+excess_reduction)`，不是总梯度下降百分比。

|任务|活跃位置平均权重（1为不减弱）|超额rep KL减弱|ΔAUC|Δ末段|
|---|---:|---:|---:|---:|
|pendulum_swingup|0.896|10.00%|+658.93|+686.32|
|walker_run|0.676|38.62%|+390.56|+455.24|
|finger_spin|0.626|45.90%|−3.17|+69.98|
|finger_turn_easy|0.846|18.16%|−87.09|−102.76|
|walker_walk|0.760|29.81%|−1.25|−5.84|

finger_spin、walker_walk已经有明显减弱，仍没有AUC提升；pendulum减弱较小却改善很大。因此“减弱得越多，收益越大”不符合这批描述性结果。这不是跨任务因果检验，也不排除某个任务使用较大或较小alpha可能更好。

## 应区分的原因

1. **baseline已接近高分，末段提升空间小。** cartpole_balance、walker_stand、walker_walk的baseline末段约994、976、966。此时应同时看学习速度；不能只用最终分数判断是否有帮助，也不能把小差值宣布为等效。
2. **优势出现在不同阶段。** cartpole_swingup的AUC提高108.99，末段仅提高5.96，主要是更快学会。finger_spin全程AUC略低、末段较高，而末段优势依赖100万点跳升，尚不能称持续优势。
3. **减弱已经发生，但任务未从中受益。** finger_turn_easy两指标下降，finger_spin门控较强而AUC未改善。可能原rep约束对该任务仍有帮助，或D没有选中有益位置、减弱发生在不合适阶段；这些都是待验证机制，不是已确定根因。
4. **关键早期阶段可能作用不足。** hopper seed0前5万活跃权重约0.995；pendulum前5万约0.9977。不能只用全程均值认定关键窗口已经充分检验门控，但也不能据此推断加大alpha必然解决失败。
5. **单训练seed无法分离参数影响与随机路径。** hopper补seed1/2/3均未重复seed0近零失败，但2/3低于baseline；pendulum已有只读复核发现首次更新前图像/动作就存在细小差异。10个评价episode不能当10个训练seed。这些事实要求保留不确定性，不用于剔除失败seed或否定全部结果。

actor尚未学好时，任务重要信息可能尚未反映在动作分布差异D中；actor对某信息敏感，也未必说明减弱该位置rep约束有利。调大alpha只会加强已有门控选择，不能让D自动成为更好的重要性指标。过强减弱也可能损害潜状态与预测先验的配合；这一潜在代价尚未由当前两组实验单独检验。

“参数太小”比较有力的支持应来自：相关学习阶段、free-nats活跃位置的权重持续接近1，并且在预声明的参数敏感性实验中更强门控重复改善。当前只有前一种诊断的局部线索，没有后一种因果证据。
