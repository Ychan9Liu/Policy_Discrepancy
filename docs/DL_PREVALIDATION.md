## DL 研究主张

1. **可证伪的信号主张**：在冻结模型、独立轨迹和合法的像素背景干预中，奖励预测支持可减少背景造成的新增保护；在另有真实环境动作后果证据的位置，仍能提供有区别的有限保护。预测优势不是动作收益的定义，也不是 posterior 正确性的标签。
2. **压缩机制主张**：只在原 free-nats 之后乘 detached 标量，活跃 rep 梯度按权重缩放；真实轨迹中还必须存在有意义的活跃保护与超额 KL 释放。局部数学恒等式不代表总 optimizer 更新同比变化。
3. **选择主张**：其选择对应关系的作用应超过单纯减弱压缩、粗粒度 D/K 分配，以及强度匹配的 reward-only。正式性能提升仍是待验证假设，短跑不能替代正式实验。

保留最强反例：行为动作泄漏 cue；mode 跳变；模型共同错误／训练支持偏差；奖励伪相关；正部截断偏差；H1 对延迟与随机事件漏检；混合因子被整体保护；早期 actor/reward head 不成熟。未检测到某反例不能宣布它不存在。

### DL-B 初版接口

独立 `agent.dt_latch` 默认 off，alpha=20、rho=.5、KL 浮点容差 1e-5；free-nats=1、原损失 scale/梯度开关保留。H1 采用共享 h、q/p categorical mode、`prevact[t+1]`、真实 `reward[t+1]`，确定性 `_core -> _prior -> mode -> reward head`。不吸收未来观测，不新增参数、probe RNG 或训练状态，probe 和最终 gate 均显式 stop-gradient。

有效 mask 为 next 存在、当前非 is_last、next 非 is_first；next terminal 奖励允许，尾部／reset 返回 v=1。非法有效数值显式失败；不把不可用位置或空活跃集合当作非法信号。baseline/off、alpha=0、rho=0 的状态、参数、训练随机流及更新等价须实际验证，不能只看代码。

### DL-C 数据和独立标签

首任务自主选 `dmc_quadruped_walk`，沿用 clean 64×64 RGB、proprio=False、repeat=1、size50m。优先只读复用已完整审计的 baseline checkpoint，初选相距至少 100000 训练动作的两个阶段，按文件实际可用性固定来源与哈希。若需重新取得模型，另记 DL 独立训练，不改或恢复既有 v1 作业。

每个 checkpoint 32 个完整独立 episode：8 calibration、24 blind；每 episode 最多 32 个按预定等间隔选的位置，均需有后续 10 个动作。随机种子、采样位置、checkpoint 先冻结；盲测中不得选择更好看的 episode。统计重采样单位为 episode，bootstrap=2000；episode 区间只描述该固定模型，不代表跨训练 seed 泛化。

- **背景干预**：MuJoCo segmentation 的全部 geometry（含 ground）及一像素边界保留，只替换其补集；审计被保护 RGB 逐像素相等，真实状态/action/reward 相同。记录可变面积；没有可变区域则此项不充分。segmentation 不自动证明所有视觉任务语义保留，须检查示例图。
- **cue 剥夺**：遮挡 body geometry，只作为观测剥夺试验；遮挡也可能损坏接触视觉，不能直接把所有遮挡位置标为关键线索。
- **外部后果**：从同一 `mjSTATE_INTEGRATION`、环境 counter、task 状态/RNG 复原，首动作分别用 q/p actor clipped mean，之后使用共同记录的 9 个动作；报告 H1 与 H10 的真实 reward 差。先重复同一动作序列并对照采集 reward，任何复原失败都停止该标签比较。这是有限候选动作下的后果证据，不是最优动作或完整策略价值。
- **动作泄漏诊断**：训练信号仍采用记录动作；另在固定候选动作上只读比较奖励预测支持，不能将离线动作分支悄然改成训练 gate。

自主筛选门槛：H10 平均 reward 优势≥.01 为 positive，≤0 为 negative，中间为 gray；盲测正负均至少覆盖 8 episode、128 位置才有足够标签。保护量 C=1-v 的 AUROC 点估计≥.60 且 episode-bootstrap 95% 下界>.5。cue 使用另一个外部标签：同状态 clean 与剥夺观测的首均值动作、共同续行动的 H10 平均 reward 损失≥.01，至少覆盖 8 episode、128 位置；只在这部分比较保护量，clean−deprived 配对均值差下界>0、点差≥.01。背景新增保护均差的 95% 上界≤.01。`m & rawKL>1` 至少覆盖 8 episode、128 位置，超额 KL 释放占有效超额至少 1%。这些是事前工程/科研筛选选择，不是已验证的普适常数。缺覆盖标为证据不足，门槛失败与工程故障分开。

总体 C/后果的相关性可能完全来自 D，不能单凭上项 AUROC 支持第二信号的增量价值。还须联报 D/fD、e、K、C 和 S：首选配对 episode bootstrap 的 `AUROC(C)-AUROC(S)` 95% 下界>0，并在冻结 D/K 层内检查有符号支持与外部标签的关系。缺层内覆盖或增量区间无法裁决时，该主张为证据不足，不自动进入短训练。每 checkpoint 分别审计，不通过阶段混合掩盖失败。

当 κ_S>0 时 S 保护量与 D 单调等价，诊断脚本的 C−D AUROC 差可用于上述比较；κ_S=0 时比较退化，不能用 D 的 AUROC 冒充有效的 S。D 包含策略方差差异，而外部标签只比较 clipped mean 动作。须报告高 D 的均值/方差贡献；若其中多数位置方差贡献大于均值贡献，当前均值动作证据不足，阻止无条件进入短训练。可后续另立版本加入共同噪声采样动作诊断；目前不把方差差异标为无价值。

### DL-D/E 对照与短训练

六组为 B baseline、D 原 Dt、N DtLatch、S 强度 Dt、P 条件置换、W 强度匹配 reward-only。设 E=(rawKL−tau)+，校准集合只用 8 calibration episodes：

```text
kappa_S = rho * sum(m*E*e*fD) / sum(m*E*fD)
lambda_W = rho * sum(m*E*e*fD) / sum(m*E*e)
v_S = 1-m*kappa_S*fD
v_W = 1-m*lambda_W*e
```

分母为零或非有限时相应比较未校准，不填默认值；S/W 只匹配校准集合超额释放，不声称全程梯度相等。本版选冻结 checkpoint 的 8 calibration episodes，不采用审查 DL-R7 中的候选训练窗口 `[20000,40000)`；阶段差异和训练中匹配漂移须实际报告。P 使用校准 D tertile、活跃 K median，重复边界合并，并分开 m/活跃性；置换完整 v，使用独立 PRNG，不消耗 baseline key。盲测分开报告索引移动率、实质权重变化率（差值>1e-6）、singleton、移动释放量及 weighted-excess 变化；活跃且原有保护的位置实质权重变化率不足 50% 或 weighted-excess 变化超过 10% 则该对应关系对照解释力不足，不当方法失败。只交换相等权重的索引不是有效对照。

短训练只有在 DL-B/C 和对照有效性满足后才启动，独立 DL 目录。初步自主预算为一个任务、六组、3 个训练 seed、每组 100000 动作（最多 180 万动作），统一从头训练；评价 0/25000/50000/75000/100000 各 5 个完整 episode，保持原 sampled 动作和独立评价随机流。此预算是前验证候选，启动前需以真实诊断校准文件冻结完整配置及版本；阶段未通过不得先跑短训练。先验约 20.4 GPU 小时的纯训练量基于旧吞吐，新增探针、编译、评价和实际资源均待实测，不能承诺总时长。

没有小样本性能检验的统一胜出阈值；逐 seed 保留短跑 AUC/return/活跃释放/资源，仅判断机制是否运作、是否出现明确灾难性退化和对照是否有力。正式性能主张须另冻结正式协议与统计功效；不得把这轮 100k 结果命名为正式 M2 验收。
