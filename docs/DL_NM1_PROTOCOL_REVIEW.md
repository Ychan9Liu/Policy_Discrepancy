## 问题、假设和最强反例

本对象问：在固定完整N1M和普通历史buffer上，**只减少普通位置的rep压力**，是否改变真实更新，
并保留固定读出族可访问的任务状态量？这种改变是否超过标量释放、位置置换与reward-only的解释，
以及是否与完整Agent行为相容？

工作假设为：B的普通完整更新会降低某些任务状态量的有限可访问性；N_nr可部分避免；
有效S/P/W不能完全解释这一增量。预期现象必须同时按实际梯度、重拟合读出和native行为区分。

可证伪反例包括：N只改loss标量却不改可表示的梯度/参数；B没有该任务信息损伤；
N与S相同好；N不优于有效P或W；只有旧head失效而refit恢复；只有p改善而q不降；
读出改善但行为不改善或严重退化。信息与行为都改善也不证明唯一中介、MI总量或所有任务稳定性能。

## 干预的最小性与新语义

设原H1邻接mask为m，当前真实is_first为r，A=m·(1-r)，E=(K-1)+，f=1-1/(1+20D)。
这里排除的是**保护干预**在reset上的作用，不删除reset loss，不改变free-nats或原loss的mean分母。
所有臂仍完整执行rec/dyn/reward/con/imag/repval/rep和原有梯度开关，保留原optimizer/moments。

| 对象 | 普通位置权重；所有其它位置v=1 | 只回答什么 |
| --- | --- | --- |
| 0 | 不更新的共同完整初态 | 前后可访问性与行为anchor |
| B | 1 | 新有限离线对象的原完整loss基准，不是历史B组重演 |
| N_nr | 1-A·ρ·e·f | 原候选在普通位置上的有限因果作用 |
| S_nr | 1-A·κ·f | 是否仅由这一标量释放总量解释 |
| P_nr | 在A/活跃性/D/K层内置换N_nr完整v | 层内对应位置是否重要 |
| W_nr | 1-A·ρ_W·e | 去掉Dt后同一支持信号是否已足够 |

`dreamerv3/dt_latch.transition_mask` **没有排除当前is_first**，所以N_nr不是原N已实现的行为。
若采用，须新增显式DL配置，例如`normal_only=False`为兼容默认、本对象显式True，
经旁路/梯度/真实批次验收后执行；不猴补原RSSM，不悄悄改变旧N、M2或旧裁决。
本对象的阳性只涉及普通子集操作；不能直接写成原完整N或部署版本已经有效。

不需要强D臂来回答上述问题：既有固定输入已证明合法ρ不能把原N提升到强D释放量；
应把S/W减弱到N，不能把ρ≈19.75、清momentum、冻结prior/actor或删除其它loss当公平补救。
全rep-stop也不是N必须战胜的保护上界。

## 数据、时序和共同随机流

使用已完整认证的1280 NPZ/16链持久化buffer和`dl_normal_replay`私有适配。
cal与训练计划分别采用PCG64命名空间`[20261101,0x4E4D4341]`与`[20261101,0x4E4D5452]`，
按官方合法65 starts均匀有放回生成128与4096个16-start批次，全部UUID/index事前封口。
两个计划在同一buffer中可能重叠；这是独立随机流，不是独立数据副本，须报告重复与源链覆盖。
不能按D/e、阶段、reset或后果筛训练窗口，不能把重复访问当独立科研样本。

每臂从相同原始cache重新开始，保留官方annotation与Consec(64,1,prefix1)，不Prefetch。
实际时序为prepare_batch→train→要求delayed outs/metrics为空→take_train_result取得当前更新
→strict_update，输出完整64个stepid必须对应原批次[:,1:]。训练seed0及原n_batches连续派生
相同训练root；P的独立置换不消耗该root。实际生效配置、P种子和counter映射必须封口。
后续cache/carry/norm分化是干预后果，不强迫它们继续相同。不是恢复原online sampler/queue/env。

每臂成功更新4096次，否则该臂不完整；不给失败样本重编号、不延长U。
评价前后完整训练状态、optimizer/counters/cache必须不变，原始NPZ始终只读。
私有cache每臂约30.6GiB以上，RAM与GPU显存分别规划，串行释放各臂主机缓存。

## cal封口、tiny N与对照效力

所有cal计算在共同完整初态上只读进行，不累计128个学习更新；使用真实普通批次和训练key。
κ=ρ·Σ(AEef)/Σ(AEf)，ρ_W=ρ·Σ(AEef)/Σ(AEe)，只算一次，均须在[0,.5]。
记录解析F64汇总、实际转换后的F32系数以及实际F32前向权重形成的释放。
分母零、非有限或实际释放无法匹配均标为未校准；不填默认值、不在评价结果后调系数。
建议cal实际S/W释放相对N偏差≤1%作为本对象的标量匹配资格，零N释放不定义比值。
这比“系数公式合法”更强：tiny权重可能在F32减法或后续BF16梯度中舍入，必须实际检查。

先做以下**干预存在性/覆盖资格**，它们不是功效计算或信息有效性证据：

1. cal有至少128个不同原始位置、覆盖至少8条原源链，在A=1、K>1且实际F32 v_N<1。
2. 对每个cal批次，在同完整初态、输入、carry与key上求B/N的完整梯度与函数级完整optimizer反事实；
   不把新norm或optimizer state提交回共同初态。至少16/128批次的encoder或posterior路径真实梯度
   和一次实际参数位移均与B不同。联报全部128个差值、模块范数/方向、非零参数数及ULP尺度。
3. 同图同输入B/B重复及ρ=0旁路用于识别实现/数值误差。要求基准重复字节一致；若不一致，
   先判测量未合格，不能把噪声当N作用，也不根据观测误差临时放宽容差。

这些数量是本提案的覆盖筛选选择，不是普适阈值。失败时停止这一普通总体对象，结论为
“当前候选/初态/精度下未形成足以检验的普通干预或覆盖”，不能否定所有稀有子群。
通过也不能宣称4096更新必有可检测收益；仍须完整记录训练累计释放、每模块真实更新和终点差异。
既有r3 v≈.999685、释放≈.3466%只说明旧对象作用弱，不说明信息已经丢失或收益必然来自减压。

P使用cal普通活跃位置的D tertiles及raw K median，重复边界去重并封口，独立区分A/活跃性。
置换完整v；保持原独立种子0/实际opt step的PRNG支路，不影响NJ训练流。
cal及整个训练内分别核原活跃保护位置的实际权重变化率>1e-6：至少50%，且P实际释放相对
**同P当前state的N目标**偏差≤10%；不以索引移动率替代权重变化，不临时粗化分层求通过。
不足时P无力，不能说对应位置无关。singleton/重复权重/覆盖全部报告。

S/W训练中也联报实际释放和在其**自己当前state上**的固定N目标释放；建议累计相对偏差≤10%
才解释为本对象的标量释放近似控制，未达时只保留B/N因果结果与不充分的对照。
W原代码若设config.rho=ρ_W，现成candidate_excess_release也用ρ_W；它不是ρ=.5的N目标，
须另用固定N定义计算，不能直接误用该字段。跨臂实际累计释放差同时报告，不能调回同一个数。
学习后的K/e/cache差是中介，跨臂剂量差不能简单叫初始混杂；标量匹配不证明梯度或Adam位移匹配。

新namespace须有真实public-policy/key对接，不冒用旧R4/R5白名单或bundle版本。

## 有限读出与统计判据

每个模型从真正reset沿共同RGB和**source实际raw**连续重建q历史。normal-reference每episode
只重建一遍并在14个current t提取；R5则按每unit自己的完整prefix提取，不拼成一条虚构历史。
p与q共享该模型当时h。
不用旧dyn cache/旧carry，不喂模型自己新预测的raw；p query不进入后续q历史。
概率比actor一次sample更丰富，结论只关于分布接口可访问性，不能叫actor已利用该信息。

对每个模型、h+flatten(q probabilities)、h+flatten(p probabilities)分别refit，h-only只描述。
family0–7拟合、8–31评价，family内各状态等权。全部模型用同一标签、配对身份和划分。
每输入组只用拟合点求均值μ和s²=mean||x-μ||²，再取(x-μ)/s；
不是逐坐标std。s=0的组固定为零，不由评价数据重新启用。拼接h与概率组得Z，取校准kernel
ZZᵀ/n_fit，其trace≤2，λ=.1时斜率effective df≤20，另有一个无罚截距。
唯一目标mean MSE+.1||β||²，不搜索λ、维数、标签或非线性probe。

velocity_x风险为主，upright与绝对p/h风险为辅助；分报物理单位MSE及除以拟合标签方差的NMSE。
拟合标签方差为零则对应归一化比较不可用，不以0/0填完美。常数读出风险和标签覆盖一起报告。
新source是后续探索性数据；不能承诺跨任务、训练seed或所有表示读出族。

主有限链的两个配对风险量为：d_damage=R_B(q)-R_0(q)，d_rescue=R_B(q)-R_N_nr(q)。
建议分别要求family-bootstrap双侧95%区间下界>0，且点估计≥.01倍拟合标签方差，
才称本对象有可测的有限损伤/保护相容模式；.01是本提案的实用筛选选择，不是已证常数。
bootstrap沿已采用读出规范：10000次、seed20261040，只重采24个评价family，
先求family内均值，不重拟合、不条件筛高D/e/U。
这些区间条件于原8个拟合family、固定模型/训练随机流及其标准化/读出，不传播拟合family
重拟合或训练seed不确定性，也不是随机化精确CI；各对象逐state/label/顺序的配对身份须认证。
保留全部连续值与区间；区间跨零是有限程序不确定，不是等效或普遍无信息。

若B没有绝对q风险上升，N比B好只能叫促进学习/改善该probe，而非避免B的信息损伤。
若p风险下降但q不变，允许prior追上解释；若仅固定旧head失效而refit恢复，允许坐标解释。
即使refit风险上升，仍只涉及固定可访问性，不等于信息论删除。

## Native、分阶段推进与结论强度

每个实际完成对象固定32个新episode：环境seed=32768+j、建议真实EVAL seed=0x4E4D4500+j，
counter从真正reset连续0..999，j=0..31；真实posterior+sampled actor+各自反馈，无context替换。
组顺序在启动前以seed20261103生成一次置换并封口，组间fresh worker/环境，单卡串行。
同episode计划配对不保证RGB逐位相同；这里测操作性native表现，保留旧pixel-identity失败原结论。
主指标为实际F64 reward的episode return/1000，实际true terminal按完整episode记录，
不制造后续transition。配对bootstrap固定10000次、seed20261104，单训练seed不冒充32训练重复。

建议预先封口全六对象的计划，先执行0/B/N_nr/S_nr。若干预或匹配资格失败，停止对应强主张；
若有限损伤/保护链没有建立，不追加U或有利样本，保留明确否定/不足，不必为该链继续消耗P/W。
若链建立且P/W事前cal有力，再从同完整0按原已封口计划执行P/W；不重新训练更有利的N/B。
该阶段条件及全部比较必须一开始公开，后续单项区间不解释为选择后仍精确覆盖的检验。

| 证据组合 | 最多支持的结论 |
| --- | --- |
| cal作用真实，但风险无可测改变 | 工程/干预成立，有限机制未支持或精度不足 |
| B损伤、N保留，S也有保留模式，但N未建立相对S的优势 | 普通rep减弱的有限保护相容证据，一般释放解释未排除；不能把不显著叫等效 |
| N优于有效S/P/W的主q风险，三个差的95%下界均>0 | 对预先定义标量释放、层内置换、reward-only解释有对应增量；不排除所有强度/任务信息替代 |
| 上述信息链加N−B native下界>0且点差≥.01 | 单初态/单任务/有限预算下的信息保护与行为改善相容，不识别唯一中介 |
| native明显退化，95%上界<−.02 | 该有限对象有≥20 raw return规模的明确损害，停止当前性能候选 |

没有native阳性CI不能直接否定信息链，也不应把“跨任务/训练seed正式性能已证”当进入正式验证前提。
native区间宽时须标性能未知，不能靠不显著宣称安全或非劣。有限机制与有效对照成立、行为无明确
灾难性反证，可论证值得正式检验；正式性能、泛化和稳定性仍由之后独立协议检验。
只有N优于S/P/W的全部预定比较才作完整选择性支持；零散胜出保留为描述，不挑最好的对照作结论。
尚不能排除nuisance/OOD、action泄漏或任意非线性D/K解释，必须保留相关局限与后续必要诊断。

## 若原N仍tiny，是否修订候选

本次首选仍是如实检验NM1-N_nr，不以cal/终点未过为由自动换候选。
若证实原e幅度在BF16总更新中不可分辨，**可另行论证**版本`DtLatch-normalized-support-r1`：
g(e)=e/(e+s)，s为独立普通cal上、以AEf加权的正e中位数；仍α20、ρ=.5、g(0)=0、0≤g≤1。
s≤0或没有正支持即未定义，不补epsilon制造保护；S/P/W也须用同一新g重新定义与匹配。

科学理由只能是：exp(-KL)支持差不是经过任务重要性标定的保护剂量，其尺度和梯度精度可能
妨碍检验；新版本把支持排序与最大释放幅度分开。它不是证明原gate无效的因果根因，
也会放大正部截断/共同模型错误/噪声，故独立任务读出和有效P/W尤其不能省。
该候选不是已采用设计，不与原N混报，也不是看到阴性后在同数据/终点上搜索s求阳性。
若以后采用，须新版本、新封口的cal/训练/评价计划与完整判败规则，保留原对象结果。
