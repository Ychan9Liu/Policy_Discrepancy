# DL 必要修订分支：独立理论建议

版本：`DL-revision-options-r0`，2026-10-10。**状态：建议与触发条件，尚未采用。** 本文由独立审查 Agent 编写，不修改 `DL-protocol-r1`、现有源码、主诊断阈值或实验配置。根 Agent 须先完成 r1 的原定裁决，再依据实际证据决定是否另立候选与新验证协议。具体选项不等于用户逐项确认的设计，也不等于方法有效的结论。

## 1. 证据边界和完整目标

本建议只参考冻结 r1、代码定义及独立资源 pilot：300k baseline、seed20261011、2 episode ×4位置；没有读取32 episode主诊断结果。该 pilot 的科学代码为 `9e6da39e59ad347f53db93af649dc8e8b63425ad`。它不能提供8/24主诊断的覆盖、区间、增量或方法验收。

pilot 可核对的事实是：真实物理重复误差最大为0、评分参数未变、先验动作/std/reward logits在四种观测间逐点相同、输出有限、TwoHot/gate数值可独立复算。clean 的8点均有rawK>1，6点有e>0；C=1−v均值0.001543、最大0.007438，超额KL加权保护约0.1075%。H10后验首动作相对先验的收益达到.01的点为0；背景a一个位置使C增加0.035339。近tie扰动的categorical KL仅约1e−5量级，但C变化可达0.005868。**这些只提示可能的失效来源，不能据8点否定候选或降低门槛。** 数值证据位于ignored目录 `analysis/outputs/dl-prevalidation/bootstrap/pilot-independent-numeric-summary.json` 与 `pilot-independent-integrity.json`。

完整目标仍是形成可正式实验的明确方法：有可证伪的目标、有独立证据表明信号辨别目标、有真实活跃梯度保护、有有效替代解释对照，并能按冻结代码/配置复现。工程通过或一个新的公式并不足以完成此目标。若r1不充分，应继续有原因的修订；若所有必要分支都不支持目标，应如实报告未形成可正式实验方法，不能把任务改称“工具开发已完成”。

## 2. 先明确需要保护的情况

本文建议将“后验包含控制信息”进一步区分为以下情况，避免把不同外部标签混为一谈。

| 情况 | 外部证据需要说明什么 | 对保护后验的含义 |
| --- | --- | --- |
| 后验在共同历史以外增加当前控制所需信息 | 同h下，q分支实际动作/策略后果优于p，并且真实状态或线索干预能独立说明该信息有控制价值 | 最接近原目标；收益与真实线索必要性应同时有覆盖 |
| 线索有用，但共同历史/先验已经足够 | 剥夺线索损害q控制，但q相对p没有增益 | 不自动需要额外保护后验；低D/C可能是合理结果 |
| 信息只影响后续决策，当前actor不依赖它 | 真实较长后果或独立动作集合显示关键性，但当前q/p策略近似相同 | 当前D门控可能漏检；需要明确扩展为时间上的控制信息主张 |
| 观测改变模型/策略，但变化不改善控制 | 合法背景干预或非关键新奇状态改变D/K/e；外部收益没有支持 | 是假保护的候选反例，不能由内部指标自行排除 |

pilot唯一cuecost≥.01的位置也有q−p H10收益<0。这说明“剥夺会损害q”与“后验比先验新增信息”并不等价。**建议**未来修订将cue必要性与q/p增量列成两个外部标签及其交集；不得事后把r1原cue门槛替换成该交集后宣称r1通过。

低标签覆盖有三种不同原因：任务/阶段的后验增量本来稀少；有限候选动作或后果定义看不见它；模型/actor尚不能利用它。它们分别需要范围限定、标签改进和模型能力证据，不能统一解释为“样本不够”，也不能统一解释为方法错误。

## 3. 触发树：先识别原因，再采用最小修订

下表均为**未采用建议**；“触发”指r1按原规则裁决后支持该问题，而非pilot一个点触发实施。

| r1可能裁决 | 首选检查/修订分支 | 不应采取的捷径 |
| --- | --- | --- |
| mode敏感，代表状态解释不稳定 | R-M：共同随机数categorical采样、边际奖励分布；单独核对policy-mixture差异 | 对argmax加任意噪声或挑一个好看的sample |
| 正例/cue交集低覆盖 | R-I：真实关键状态干预与有限动作集合证据；R-L：改进后果范围 | 下调正例阈值、盲测后挑位置或扩大n直到显著 |
| 独立选择有支持，但有效保护弱 | 先分解D、e、m、K活跃度和梯度作用；仅在原因明确后冻结强度修订 | 默认提高rho/alpha，或用rank变换放大到通过 |
| H1支持漏掉真实延迟收益 | R-H：多步奖励预测支持，配合R-L真实后果 | 只延长标签H，仍把H1代理叫长期价值 |
| 背景假保护、D贡献已足以解释C | 优先R-M排除代表误差；之后R-K独立条件判别/可靠性证据 | 以大K、正e或共同模型一致性当真实价值 |
| 强度S/W与N等价，或有效P保留效果 | 重新审查D/e对应关系是否必要；必要时简化主张/方法再验 | 增加复杂度并把工程复杂度当科研贡献 |

任一新方案都须新命名、新SHA/配置、新校准和新独立留出数据。r1盲测可作为已公开失败分析，不能再称修订版本的未见数据；不得在同一结果上试M、H、K阈值到通过。

## 4. R-M：少量共同随机数采样与预测混合

### 4.1 它解决的可识别问题

argmax会在近tie处跳类别，即使分布KL很小；从mode开始的奖励预测和actor输出可能不代表模型实际使用的随机latent。Dreamer的RSSM本身采用随机categorical表征，因此对其边际预测进行诊断有模型依据；这并不自动证明边际信号能辨别控制价值。[Dreamer原论文](https://www.nature.com/articles/s41586-025-08744-2)

**建议**对同h下的q(z)、p(z)，每个factor用同一组Gumbel噪声获得L个配对样本；q/p之间共享噪声，不同L/位置/时间之间使用独立命名key。必须采样已含正确unimix的实际分布，不再次混匀。当前与下一步prior都应积分或采样；只替换初始mode而保留下一个脆弱mode不能解决全部问题。Gumbel-max产生categorical样本的原理见[JAX官方文档](https://docs.jax.dev/en/latest/_autosummary/jax.random.categorical.html)；实际实施接口须核对仓库锁定的JAX0.4.33，不能直接采用新版文档的额外参数。

共同随机数保持q/p边际正确，主要用于降低配对差的方差；它不是额外的真实反馈，也并非任意非线性网络下都保证减小方差。因此须实测与独立噪声的方差，而不是预设其优越性。[Glasserman与Yao原论文](https://pubsonline.informs.org/doi/abs/10.1287/mnsc.38.6.884)

### 4.2 奖励分布应先混合概率，再评分

记第l条路径的TwoHot reward概率为R_q,l与R_p,l，可定义候选：

```text
Rbar_q = mean_l softmax(logits_q,l)
Rbar_p = mean_l softmax(logits_p,l)
d_q = KL(y || Rbar_q),  d_p = KL(y || Rbar_p)
signed = exp(-d_q) - exp(-d_p)
e_mix = positive_part(signed)
```

bins/target沿用准确TwoHot编码。log-average概率可用logsumexp稳定计算。不能平均logits后softmax，也不能把平均路径CE或平均positive_part称为混合预测的评分；它们是不同统计量。特别是平均各路径的正部会把“有时q占优、有时p占优”偏向保护。混合预测与评分形式的匹配有一般统计依据，但这里的RSSM应用与控制收益关系仍是工作假设。[预测分布原论文](https://arxiv.org/abs/1608.06802)、[proper scoring原论文](https://sites.stat.washington.edu/people/raftery/Research/PDF/Gneiting2007jasa.pdf)

L=4/8/16可以作为**待冻结的校准候选**，不是推荐默认值已获批准。应在独立校准点检查重复MC key下的signed/e/C误差和排序稳定性，以少量更大L作数值参考。L增大使估计稳定，不保证信号增大或主张成立。实际训练需要独立probe随机源，按update/位置等折叠，不推进原policy/train RNG；输出和最终gate继续detached。

### 4.3 必须重新定义D的语义

真正的状态条件策略边际是：

```text
Pi_q(a|h) = E_z~q[pi(a|h,z)]
Pi_p(a|h) = E_z~p[pi(a|h,z)]
```

以下三种D不能混称：

| 候选 | 优点 | 新反例/解释限制 |
| --- | --- | --- |
| 平均配对条件Normal距离 | 可复用原analytic算式，成本低，q=p共享噪声时应精确为0 | 是所选coupling下的条件距离；即使两个策略边际相同也可能非零，不能称精确mixture距离 |
| 边际一二阶矩距离 | 将latent不确定性纳入total variance，少量样本易估 | 均值/方差相同的多峰策略仍可不同；未clip的Normal矩与实际clip后动作矩不同 |
| 实际动作mixture的MMD/energy或可计算density的KL | 更接近完整策略分布；可比较方差贡献 | 小L有统计噪声，kernel/密度语义和action边界必须冻结；不是原Dt量纲 |

若采用矩，必须使用 `Var(a)=E_z[Var(a|z)]+Var_z(E[a|z])`，不能只平均actor的conditional std。实际动作有clip时可直接共同噪声采样并clip；用未clip Gaussian密度给有边界质量的实际动作评分会产生错误解释。

首选**建议**先做边际reward与上述D的诊断比较，只在预先限定的校准数据上选最小可靠估计器，再在新留出数据验增量；不能同时改三个D、H和gate后无法归因。若耦合距离已经解决工程稳定性，仍须将它准确命名为coupling surrogate，并加入策略边际相同的反例。

### 4.4 新反例、成本和必要证据

新的反例包括：稀有关键latent被小L漏掉；两个边际预测共同错误；正部截断的有限MC偏差；把边际化得到的平滑误称因果辨别；同一reward target/行为动作仍泄漏cue。q=p、label shuffle、共同错误、posterior有预测信息但actor无依赖、背景改变logits而无真实收益都须保留。

额外模型前向约随L增长，GPU训练总耗时不会简单等于原来的L倍；若也对L个动作做真实后果，则外部物理步数近似随L×H增长。显存依赖批量、并行展开和是否分块，不能由原size50m单卡可用推断L16/H50无风险。

必要证据是边际正确、q=p精确零、MC方差/样本量稳定、近tie扰动不再由代表选择主导、完整私有RNG/旁路/梯度验收。进入方法验证还必须有新独立控制后果标签和有效S/P/W；以上数值通过本身不足。

## 5. R-H：多步奖励支持

### 5.1 目标与定义选择

该分支针对真实延迟奖励信息；不能由弱e直接推断应采用多步。**建议**先证明H1误差与较长真实收益有系统对应，而不是只因为多步能输出更大数值。

可从同h、q/p初始分布出发，以共同记录动作序列进行H步预测，不吸收未来观测，并对每步真实reward评分。一个容易实现的候选是平均marginal TwoHot KL：

```text
d_q,H = mean_j KL(y_(t+j) || Rbar_q,j)
d_p,H = mean_j KL(y_(t+j) || Rbar_p,j)
e_H = positive_part(exp(-d_q,H) - exp(-d_p,H))
```

它是H步**边际评分的平均**，不是完整reward序列的joint likelihood，也不是策略价值。直接exp(−sum_j KL)可能随H指数衰减；改为平均改变了量纲/解释，必须新版本。对联合预测做严格评分需要处理跨时间相关与混合路径，不能把独立边际相乘冒称联合模型。

H1/H3/H10等只能列为待冻结选择。长H先看world model在对应动作分布上是否能做有用预测；若q/p都错，增加H通常增加偏差。未训练的长程return head、critic预测或模型自判“关键”都不能替代外部标签。

### 5.2 动作泄漏和mask是实质设计问题

后续行为动作同样可能包含未来cue信息，使prior在条件预测中借到信息。这不使记录动作下的预测分数非法，但它不能识别未条件化的观测价值。诊断应补独立固定动作序列及其逐步真实reward；不能用行为reward给改动后的动作序列评分。

H步需要完整有效后续窗口：禁止跨reset、允许窗口末terminal、明确提前terminal的处理。若信号输入T=64，则H10最多54位置有完整窗口，H50仅14位置；比H1少的coverage不能隐去。各对照须使用同一m_H与评价口径。gate继续作用于t处原free-nats后的rep项，不改变其梯度边界。

### 5.3 新反例、成本和证据

反例是模型误差累积、长续行动补偿了错误首动作、未来action编码线索、延迟收益只出现于极少episode、奖励边际相同但joint事件不同。模型前向成本近似L×H；有效位置比例下降，可能使平均保护反而更弱。

必要证据包括：H1与真实较长因果影响确有错配；长程reward模型在独立动作序列上有技能；多步支持减少已确认漏检且没有扩大背景误保护；边界、泄漏与S/W强度匹配重验。只有新H标签更容易达标不算代理改进。

## 6. R-I/R-L：真实关键状态干预与较长后果

### 6.1 关键性不能由D/e/K来定义

**建议**在真实MuJoCo状态上建立合法可复现的关键事件：例如从已访问状态施加有物理意义的小姿态/接触变化或短时冲量，再通过动力学得到合法、可渲染的新状态。范围和事件类型须事先固定；不把随意改RGB当真实状态干预，不制造无效quaternion或穿模状态。

共享历史可以固定到干预前；干预后的当前观测应由各自真实状态重新render。这样检验新增观测是否让后验修正过时先验。速度冲量本身不一定立即在单张RGB中可见，不能预设所有干预都有posterior可获取的线索；需核对视觉可识别性/必要观测窗口。

有限的、预先固定且独立于D/e/K的动作或短控制序列集合，可提供外部证据：两个真实状态下动作排序是否改变，错误动作的代价是否增加。仍须单独测试q/p分支能否实际利用信息。有限集合只能证明其范围内的差异，不能证明全局最优；原5个固定动作若对所有候选均无区分，不能以“零泄漏”当充分诊断。

额外状态扰动可能分布外。若方法只在受控扰动中有支持，应将该场景写为适用范围，不能外推到原clean任务常规轨迹。新的挑战数据可补主张，但不能覆盖或消除原r1的失败事实。

### 6.2 长后果必须与研究对象匹配

首动作q/p、后续共同记录动作是有限的一次动作后果。只延长H并继续取平均，会稀释短时影响；续行动也可能补偿首动作，所以不能把H50解释为完整策略价值。

**建议**按明确问题选以下一种后果，并在新协议固定归一化/折扣/终止：

| 后果定义 | 能回答的问题 | 新局限 |
| --- | --- | --- |
| 首动作后共同动作续行，较长累计或折扣回报 | 一次观测引起的首动作差异有多大持续影响 | 续行动可能偏向行为分支；标签尺度随H改变 |
| q/p初始状态分别控制，随后正常接收各自真实观测的closed-loop rollout | 初次信息差异能否产生实际可恢复/不可恢复的控制收益 | 成本更高，需每分支render/infer；动作造成的未来状态差异是因果链的一部分 |
| 固定候选短控制序列，观察真实失稳/进展等结果 | 当前状态是否改变有限动作集合的有效排序 | 任务指标需独立定义，不能用模型critic当真值 |

closed-loop分支须完整复原环境/task/RNG、采用共同环境扰动及独立命名policy RNG，真实observations不能交叉给另一分支。禁止永久屏蔽prior分支未来观察后将结果称作正常策略价值。

必要证据是物理/观测合法性、重复状态恢复、动作选择变化或真实损害、q/p实际增量及独立episode覆盖。成本主要为外部物理L×H和closed-loop的render/model前向；这类新真值最能解决标签错配，也最需要严格定义范围。

## 7. R-K：rawK联合判别与信息一致性

rawK=KL(q||p)是观测改变latent分布的量，在Dreamer内部已可取得，增加统计成本很低。它不是信息正确性、任务价值或模型置信度的保证。

| 内部现象 | 可以提出的工作假设 | 必须保留的反例 |
| --- | --- | --- |
| K大、边际D小 | 新增信息未被当前actor使用 | 信息可能关键但actor未成熟/只影响后续；也可能只是背景新奇 |
| K小、modal D大 | argmax代表误差/近tie敏感 | 真策略边际仍可能有小而关键的差异，不能据此一律抹去 |
| K/D/e都大 | posterior影响策略且改善模型内reward评分 | 背景伪相关、共同模型错误、行为action泄漏仍可能同时成立 |
| K活跃而e小 | reward支持不辨别或q/p已同样准确 | 对reward无用的状态信息可能仍对续行/终止重要 |

固定h与同一个actor kernel时有本任务可直接推导的一致性：

```text
KL(Pi_q || Pi_p) <= KL(q || p) = K
```

证明是联合q(z)pi(a|h,z)与p(z)pi(a|h,z)的KL等于K，边际化z不能增加KL。该data-processing结论只适用于真实策略边际的KL；不约束r1的modal W2代理，也不能拿有限MC超界值硬clip到K来伪造一致。[信息处理原作者论文](https://arxiv.org/abs/1405.3629)

**首选建议**先用K做既有D/K分层、检查e在固定D/K后的增量、区分large-K nuisance与真实关键新信息；再比较K-only、D+K、e-only、D+K+e，避免任意添加第三门后无法证明必要性。K在原free-nats之上仅表明rep梯度可活跃，不代表应保护；乘一个随K增加的函数还可能保护更多背景，乘一个随K减小的函数又可能漏掉真正新事件。

若采用校准分类器或K门控，这是新的方法参数化：标签必须外部独立，训练/验证分割固定，输出detached，S/P/W重新强度匹配。大K拒绝区、D/K比率、K阈值等均未采用；它们不能直接从主盲测失败位置拟合。

## 8. 弱释放：先检查信息，再谈幅度

在r1中C=rho×e×fD，且0≤fD≤1，所以C≤rho×e。弱释放可能来自：当前actor相同、绝对reward支持无增量、mask不可用、原free-nats无活跃梯度，或目标位置根本不在当前数据。提高rho只放大同一选择；不改善它的正确性，且会改变原局部保护上限。提高alpha也不突破e的上限。

把e改成loss_gap、归一化signed、rank或sigmoid可以增大幅度，但会取消/改变绝对预测兼容性的意义。例如q/p都极差时，较大的CE差仍可能把错误后验判为可靠。**尚无证据的推测**是另加预测可靠性、覆盖校准或多head一致性可能有帮助；这些模型内来源依然不能充当独立真值。

只有独立选择本身得到支持、弱作用原因明确、真实梯度/optimizer效应确实太小时，强度校准才是合理的另立候选；事前规定目标强度并在新校准集冻结，再以同强度S/P/W和新盲测检验。不得为达到1%而改阈值、rho或分母，随后称原r1通过。

## 9. 分支成本与执行顺序建议

所有数字均为待冻结候选/量级，不构成启动配置或完成ETA。

| 分支 | 主要额外成本 | 建议最小先行证据 |
| --- | --- | --- |
| R-M，L4/8/16 | probe前向/采样约O(L)；若真实动作后果也采样则O(LH) | 先独立校准数值稳定与q=p/近tie/相同策略边际反例，不立即重跑全部训练 |
| R-H，H3/10等 | 世界模型rollout O(LH)，有效窗口缩短 | 先真实延迟错配与多步模型预测技能；不能凭H大直接采用 |
| R-I真实关键状态 | render、复原、有限动作序列外部后果 | 先合法状态、视觉可获取性、动作排序/代价有区分 |
| R-L长/closed-loop后果 | 物理O(候选数×H)，closed-loop再加render/infer | 先固定因果对象、尺度和终止规则，不临时换“更好看”的标签 |
| R-K分层或新门控 | 已有K几乎无额外前向；新classifier需独立拟合/审计 | 先D/K内e增量与K-only反例，再决定是否需要新增门 |

推荐按原因顺序实施一个最小分支：r1原样裁决 → 区分覆盖/估计器/目标错配/强度 → 冻结一个修订和新增证据 → 工程/独立诊断/机制重验 → 只有前置成立后执行条件短训练及S/P/W。先做估计器稳定可减少后续标签混淆；真正缺覆盖则需外部控制信息证据，不能只做MC。

L与H同时扩展会把probe成本放大；例如L8、H50相对单路径H10的rollout工作量约40倍，而不是整个训练40倍。必须单卡实际测峰值、吞吐和CPU物理成本再排程；资源仍仅用户指定sv3物理GPU4–7，不共享/换卡。原size50m与pilot耗时都不能作为修订成本实测。

## 10. 进入正式实验的证据与停止条件

下列是**修订版需重新冻结的必要证据类别**，不是绕过r1门槛的新宣布通过规则：

1. 目标与范围明确：当前增量、延迟信息或受控关键事件选一种明确主张；外部标签不由D/e/K自身生成。
2. 估计器与工程正确：准确TwoHot/混合、实际policy边界、有效mask、独立RNG、default-off/退化、free-nats梯度及真实size50m验收，计算成本可复现。
3. 有新独立数据覆盖目标与反例：cue必要性和q/p增量分开；真实背景/物理合法性；episode单位区间；不以阶段/seed混合掩盖失败。
4. 有真实机制效应：活跃rep梯度保护及实际训练中的覆盖/强度，报告总梯度/optimizer差异；评分NPZ里的候选v不等于训练已应用。
5. 替代解释有有效对照：S/W校准、条件P实际改变受保护权重、标签shuffle、mode/采样误差、动作泄漏、共同模型错误。若简化方法已足够，应改主张而不是强行证明额外信号必要。
6. 条件短训练说明机制运行及可重复严重退化风险；正式长期性能仍是待检验假设。短预算单task/3seed不能预告长期提高。

进入正式实验的**充分工作性标准建议**是上述定义、工程、独立辨别、机制、有效对照与条件训练证据共同成立，且适用范围/主要未决反例已写清。它足以使正式性能假设具体可证伪，不等于已证明最终性能提高。统计阈值、最小实际效应、预算与覆盖应在修订版未见数据前冻结，不能照搬r1数值而不论证量纲/目标是否同一。

若MC稳定后仍无独立增量、真实关键状态中q/p均不能利用信息、多步模型无预测技能、只有放大错误权重才有活跃机制，或有效强度对照完全解释结果，应停止该分支并保留失败；是否另设任务/模型能力前置是新的研究范围，必须明确记录。允许否定候选，不允许把否定证据改写成工程成功即方法准备就绪。
