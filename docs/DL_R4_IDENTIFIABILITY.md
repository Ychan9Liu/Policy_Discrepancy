## 2. 要回答的研究问题

本轮分别回答两个有限问题：

1. **强度可行性**：固定本次 N 已经实际出现的 D/e/K/m 及 alpha=20，只改变合法 `0<=rho<=1`，能否在这些相同位置达到同 mask 的 D-only 潜在超额释放？
2. **信号可辨识性**：即使 H1 两个 reward head 完全校准、D/K 较大，`(D,K,e)` 是否足以区分当前 actor 因后验依赖而受益、无差别或受损？当前 actor 受损又是否等于后验信息本身无价值？

这两个问题都不直接回答保护后验是否提高 Dreamer 性能。还需要第三个独立命题：实际 rep 压缩是否损伤任务信息，以及保护是否避免这种损伤。

## 3. 固定 N 批次的 rho 可行域

沿用现有实现，在原 free nats tau=1 之上定义 `E_i=max(K_i-tau,0)`，`f_i=1-1/(1+20 D_i)`，`m_i` 是原 H1 有效邻接 mask。这里的 i 遍历既有训练实际消费的位置；replay 重采样保留计数，不当作独立状态。

```text
A = sum_i m_i E_i e_i f_i       # 汇总 calibration_num
B = sum_i m_i E_i f_i           # 汇总 calibration_den
R_N(rho) = rho A
R_D_same_mask = B
r(rho) = rho A/B                # 仅 B>0 且有限时定义
rho_required_for_D = B/A        # 还要求 A>0
```

`R_D_same_mask` 是在 N 自身已存批次、相同 H1 mask 上代入 D-only 公式的代数量，不是实际 D 训练的释放量。原 D 不依赖 H1 mask，故此处也不能偷换为所有位置上的实际 D 权重比较。A/B 汇总必须使用可加的原 `calibration_num/den`，不能用有效位置均值或各更新比值的无权平均替代。

既有分析报告的 `r(.5)` 约为 .0253111。因此本轮要验证的固定输入预期为：

- 合法 rho 的最大 `r(1)=2r(.5)`，约 .0506222。
- 匹配同 mask D 的 `rho_required=.5/r(.5)`，约 19.75，超出合法范围。
- rho 无法在这些固定批次内补足全部差距；这不是“把 rho 调大即可同强度比较”的情形。

执行须从已认证原证据得到完整精度、检查分母、独立重算及边界，不把上述展示舍入当验收输入。A=0/B>0 时合法 rho 始终不释放，匹配不可能；B=0 时比较不可定义，不能填 0 或默认系数。也不能反算越界 rho 后执行。

**可证伪范围**：原可加统计不一致、存在非有限或非法分母，或完整精度计算显示所需 rho 合法，均应拒绝当前数值解释。若实际比值符合上述预期，仅支持固定输入的可行域结论。

改变 rho 后的在线模型、replay、D/e/K 与轨迹不会保持不变。本计算不预测新 rho 的在线释放量或回报，不证明 rho 与性能的因果关系。`r(.5)` 也不是可直接用于新训练的正式 kappa。下一真实强度对照的首选方向是独立标定较弱的 D 形状 S，与 N 匹配；其来源、窗口和漂移规则必须另行冻结。

## 4. 有限解析反例：相同 H1 信号，三种真实后果

### 4.1 固定构造

取四个等概率 cue `C in {0,1,2,3}`，当前 latent Z 与动作 A 也各有四种。固定共享 history，不携带 C；当前后验与先验为：

```text
q(Z=C | C)=.97
q(Z!=C | C)=.01                 # 每个其它类别 .01
p(Z | history)=.25              # 四类均匀，与 C 无关
当前 actor：A=Z
```

这里采用离散确定性 actor，`D_toy=KL(Pi_q || Pi_p)`；它与 `K_toy=KL(q||p)` 相等，均为：

```text
K_toy = .97 log(3.88) + .03 log(.04) ≈ 1.21859 > 1
```

**D_toy 不是 Dreamer 实际 Dt。** 真实实现比较 categorical mode 条件下连续 actor 的策略代理，本 toy 不证明实际 Dt=K、Dt<=K 或高 Dt 的频率。该构造只提供可完全穷举的辨识反例。

第一步真实奖励 `R1` 与 C/A 独立，`P(R1=0)=.99`、`P(R1=1)=.01`。q/p 两侧 H1 head 的 bins 均为 `[0,1]`，输出完全相同的 `[.99,.01]`，且这正是真实条件分布。对两个可能标签分别计算准确 target/CE/KL，均有 `u_q=u_p`、signed support=0、`e=0`。若使用现有 gate 形式，则任意合法 alpha/rho 下 v=1。

这不是 head 不成熟、H1 预测错误或 exp 数值误差造成的漏检。构造刻意让 H1 已经完全正确，长期后果仍可不同。

### 4.2 三个 world 与当前 actor 的真实效用

三个 world 只改变 `t+2` 的 terminal reward；它依赖先前动作 A，R1、q/p、actor、D_toy/K_toy 与 H1 全部保持不变。没有借助未来观测改变本例的已定义决策。

| world | terminal reward R2 | 当前 q actor 期望 | 当前 p actor 期望 | 当前 actor q−p |
| --- | --- | ---: | ---: | ---: |
| useful | `1[A=C]` | .97 | .25 | +.72 |
| neutral | 1 | 1 | 1 | 0 |
| harmful | `1[A!=C]` | .03 | .75 | −.72 |

共同 R1 对真实累计回报差抵消。验收应对每个 cue、latent、动作与 R1 标签显式枚举，不以重新抽样近似这些期望值。

由此可得本例的解析结论：完全相同的 `(D_toy,K_toy,e,u_q,u_p)` 可以对应三种不同符号的当前 actor 效应。只使用这些量的固定判别规则无法在这三个 world 间正确区分。该结论不否定使用额外真实后果、更多历史或不同任务预测目标的可能性，也不证明真实数据必须落入本例。

### 4.3 负效用不等于后验信息无价值

为分离“当前 actor 如何使用信息”与“latent 中是否存在可用信息”，穷举四 latent 到四动作的全部 `4^4=256` 个确定性读出 `g:Z->A`，分别求 q/p 最佳期望。此处是已知完整有限 world 下的枚举，不是从有限训练集学习 probe，也不是测得 Dreamer actor 最优。

| world | q 最佳读出效用 | p 最佳读出效用 | 本有限接口的可用信息增量 |
| --- | ---: | ---: | ---: |
| useful | .97 | .25 | +.72 |
| neutral | 1 | 1 | 0 |
| harmful | .99 | .75 | +.24 |

harmful world 中，当前 `A=Z` 错误地利用 cue，当前 q−p 为负；但让读出对每个 Z 选择另一个类别即可达到 .99，优于无 C 信息的 .75。故“当前 actor 因 q 受损”“后验接口没有可用信息”“应当将后验压向先验”是三个不同命题，不能相互替换。

穷举验收须保留所有读出、q/p 各自最大值及至少一个见证；不得只枚举 identity，再把当前 actor 的表现当最优读出。最优值不能由预写表格直接复制到结果。该上界也不说明实际训练能学到见证读出。

### 4.4 rep KL 的局部方向不能证明整体丢信息

在本 toy 的一条人工语义路径上写 `q_r=(r,(1-r)/3,(1-r)/3,(1-r)/3)`，固定 p 均匀：

```text
K(r)=r log(4r)+(1-r) log(4(1-r)/3)
dK/dr=log(3r/(1-r))
在 r=.97：dK/dr=log(97)>0
```

单独减小这个 KL 沿该路径有降低 r 的方向，故它提供“压缩可能削弱 cue 可靠性”的明确反例结构。它没有执行 Dreamer encoder/RSSM、其它损失、straight-through 随机变量或保留 momentum 的 optimizer。不能据导数宣称整体 optimizer 已删除任务信息，更不能据 v=1 宣称保护将提升性能。

## 6. 下一单一真实诊断候选：先冻结干预对象

**建议，未采用、未启动**：下一项先审定“高 D 下当前信息依赖的真实 signed 效用”及其与 H1 支持的对应，区分以下两个 estimand，再决定最少需要的实际分支。不先给新样本数、horizon、checkpoint、参数或 GPU 配置。

- `U_act`：只改变当前首动作来源 q/p，当前观测处理后的 latent memory 固定为同一 q memory；以后各分支按实际动作和真实观测正常递推。它测量当前 actor 动作选择的后果。
- `U_obs`：当前一步分别采用 q/p 信息，并保留相应 memory，之后双方正常接收各自真实观测、使用正常 posterior。它包含动作和记忆路径，是一次信息差的有限闭环后果。

两者不是同一个量。即使 `U_act<0`，当前后验也可能含有将来可用的信息；即使 `U_obs<=0`，也不能直接断言信息不存在或压缩它有益。H1 支持还条件于记录行为动作，其标签与这两种 q/p 控制后果也不同，不能不声明对象就将不一致全称为评分错误。

若要把动作与 memory 路径分离，可建议四臂：动作来源 `{q,p}` × 当前 latent memory 来源 `{q,p}`。记 `V_am` 的第一个下标为首动作来源、第二个下标为当前 memory 来源，则：

```text
U_act(q-memory) = V_qq - V_pq
U_obs           = V_qq - V_pp
memory effect at p-action = V_pq - V_pp
U_obs = U_act(q-memory) + memory effect at p-action
```

四臂只是足以分离上述已定义有限路径的建议，不自动成为必须扩大到四臂的执行决定。若研究仅需总的一次信息差，两条对角臂可能足够；若要把总差归因于首动作，则需其它臂或另外论证。memory 固定指当前 latent 状态，**不能把含上一动作的完整 actor carry 机械复制给所有臂**：每臂实际 carry 的 `prevact` 必须写入该臂真实执行的首 action，后续状态按各自真实动作/观测推进。不能偷偷让 p 臂永久失去未来观测，也不能把 future q 观测交叉喂给另一真实状态。

冻结前最少还缺：目标是 U_act 还是 U_obs；当前 actor 使用 q/p 的真实抽样与 carry 契约；窗口/终止/折扣与统计精度为何足以回答该问题；高 D、正负和 nuisance 的独立覆盖依据；独立任务标签与 D/e/K 的逐位置联合记录；校准/留出隔离；普通 replay 与后续压缩效应如何接上。nuisance 损害与有用依赖可以并存，不强制二分；raw K 不作为任务真值。
