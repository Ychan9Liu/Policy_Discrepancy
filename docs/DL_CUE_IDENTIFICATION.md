版本 **`DL-cue-identification-r0`**，2026-10-11。**Agent 理论建议稿；probe／cue 科学协议未冻结、未实现、未运行。** 本文件论证下一项工作的必要性与识别条件，不修改已停止对象的门、配置或结论，不构成新物理干预、真实数据重拟合、blind 读取、gate、Dreamer 更新或训练的启动依据。root 已交叉审阅，首选准备纯合成 probe 检测范围规范；尚未采用 nested probe 或 torque。独立模型元数据核查已完成，范围与证据见 [DL_CUE_PREFLIGHT.md](DL_CUE_PREFLIGHT.md)，不能当作本稿候选实验已执行。

## 1. 已知事实与仍未识别的解释

`DL-action-information-r1` 在确定执行 SHA `f1ae4d6513e81ed680992b64ba8ebade7d256d52` 上完成全部固定 cal32、七固定首动作及八已存 actor 首动作，H20 主 9600 步与同量复放通过。外部有限动作门成立：16 状态／4 episode 动作 range 达到事前实用 margin，18 对跨 episode 的 closed δ-optimal 集合不相交。它证明这个有限控制对象需要有代价区别的状态选择，不证明当前 RGB 是该区别的新来源。

同一对象的 q/p sampled-latent λ1 LOEO 与 constant 全部选同一控制，八 episode selected-reward 增量均为零，按事前门接口增量不支持。actor q−p 为 `.0150941934522`，名义区间 `[−.0258798524745,.0544297596488]`，不确定。上一 H100 正常反馈负平均裁决仍独立保留。这些不是“latent 无信息”“prior 完全充分”或“posterior 保留必然无效”的结论。

固定输出解释已完成：constant 在 26/32 状态的 Aδ 内，另六个状态 regret>.2；q/p 特征项改善预测 MSE，但没有越过截距的控制排序。固定 λ/RMS 的 kernel 最大特征收缩为约 `.20238–.23771`。这说明该 readout 有明显收缩，不识别其是不是零选择增量的主因；不能据此降低 λ 后重判原 r1。

仍未识别的解释至少包括：当前观测相对完整历史无新增可决策信息；信息存在但 q 未保留；信息在 q 中但本固定 readout 不会利用；actor 未利用或错误利用；共同 normalized-zero 续行和近优 constant 限制效应；训练支持／OOD 与模型误差。当前证据不能把它们强行三选一。

## 2. 首选立即问题：探针是否有足够的识别能力

**建议先做不含真实目标的 probe 识别能力规范与合成反例，再决定是否需要新的真实对象。** 这是当前风险最低的准备；本文件本身不启动测试。

可以预先构造已知线性可读信号、仅历史可读信号、无信号及与目标无关高维噪声四类合成对象。保留同 episode/state/sample 聚类、同 h/z 总能量标准化、同截距与决策 margin 尺度；人为标签及其来源必须显式独立于真实 cal32。检查固定 λ1 算法在这些条件下何时能越过 constant 排序、何时只有 MSE 改善。合成构造不能伪称真实 task 信息，也不能按真实失效状态的标签拟合一个恰好可通过的 teacher。

理论上，非退化 h/z 各组标准化后训练平均平方总能量各为 1，所以 `trace(XᵀX/n)<=2`。固定 λ1 的训练特征收缩有上界；标签截距可能因此主导选择。这是算法几何事实，不证明降低正则会恢复真实 cue，也不支持旧对象通过。

合成证据的意义是检验诊断器是否能识别指定强度、维度和 margin 下的已知目标，并明确其检测范围。它不能证明模型表征的信息量或因果可用性。合成成功而真实 readout 失败仍不能否定其他函数类；合成失败则不应把相同探针的真实阴性外推为信息不存在。

## 3. 新 nested probe 是替代路径，不是回调原对象

**尚未采用建议**：若上述检测范围不足而又要回答“同一有限任务信息在模型接口中是否可读”，可以另立一个自适应正则的 probe 对象。相比立即引入 torque，它避免同时新增物理 OOD、视觉可辨和任务后果三项混淆；相比直接减少 λ，它必须把选参流程本身作为固定算法验收。

新的规范至少应满足：

- 预先固定有限候选正则集合、损失尺度、容量、选参目标、tie／退化与一次停止规则；不因 outer 结果追加 λ、模型、特征或指标。本稿没有冻结具体集合。
- outer 留出整 episode；每个 outer 训练集合内再做整 episode 的 inner 验证。所有 centering、group RMS、target centering 和候选拟合只在相应训练子集进行。
- q/p 采用相同维度、预算和正则选择规则。一个保守候选是按两接口平均 inner 误差共同选择同一个 λ，不使用 q−p outer 优势作为选择目标；是否采用仍需审查。constant 同样只能来自 outer 训练集合。
- outer 每 sample 选动作后再平均真实 reward／finite-library regret，不能把四样本当独立 episode，不能从各 λ 的 outer 结果选赢家。报告全候选 inner 收据和最终唯一算法的 outer 结果。
- 当前八 cal episode 及其成本已被观察。其新 nested 结果仍是后验校准探索，不是独立 confirmation、原 r1 翻案或 RGB 相对完整历史的新信息证明。小样本下 nested 选择也可能极不稳定。
- 真正未见判断须在新算法完全冻结后一次执行；24 blind 不能作选参、改算法或搜索赢家的集合。本稿不授权读取它，也不承诺既有 blind 足以支撑新对象。

此路径直接检查固定输入／成本上的另一事前读出算法是否有选择增量。阳性仅支持旧算法检测范围有限，阴性只停止新算法；二者均不能单独归因于 λ 或排除所有函数类。即便新 probe 阳性，也不能证明信息因当前 RGB 而新增、actor 已会利用、压缩会删掉信息或 gate 有效。若连续扩模型／网格才得到正号，应停止，而不是称识别能力不断改善。

## 4. 识别历史新信息的一条可控路径：外部随机化

以下是另一条**有条件候选**，不是已决定启动的下一实验。

设 `H_(p−1)` 为真实过去观测／动作历史，`X_(p−1)` 为完整物理／task／activation／clock 状态，`c_p` 为源生产 policy 在 p 时刻前的真实 carry，`a_(p−1)` 为已执行的原 raw 动作。一个外部事件 C 若在设计中独立于这些历史，由同一正常 transition 产生：

```text
X_p(C) = F(X_(p−1), production_map(a_(p−1)), C)
O_p(C) = actual_RGB(X_p(C))
h_p = RSSM_core(c_p.dyn, c_p.prevraw)             # 不含 C
p_p = actual_prior(h_p)                         # 不含 C
q_p(C) = actual_posterior(h_p, O_p(C))
R_C(a) = 同一明确有限控制对象下的真实 reward
```

当前 source 在 p 前 carry 已包含 p−1 的真实观测／latent 和原 raw prevaction。只改变产生 p 观测的最后一次物理 transition，可以沿用这份真实 carry；更改更早历史或跳过多步就不再成立。各分支必须逐字节核同 h、真实 prior 及所有与 C 无关的输入；C 不得通过 key、文件名、序号、privileged 状态、mask 或动作泄漏给 readout。未来若多步观察，则必须各分支按自身新观测正常推进 carry，不能保留旧 carry 面对更晚状态。

外部 C 的不可预知性有因果设计依据，不等于图像可观测或任务有用。只有同时满足下列条件，才得到一个有限的“当前观测新增可决策信息”对象：

1. **随机化与恢复可信**：事件分配规则事先独立于 H、D/K/e、q/p 后果和低 reward；按完整初态配对，task/RNG/reset/activation 与原真实 clock 保存并可复放。必须是真实正常 transition，不是 qpos/qvel teleport。
2. **RGB 可获取**：当前 64×64／camera2 实际图像中，所定义线索可被不依赖 Dreamer 内部信号的预定视觉判别或盲标识别，并超过正常重 render 差异。几何投影／像素改变仅是前置，不能代替独立可识别性；阴影、遮挡或自带标记不能泄漏事件标签。核实际 encoder 输入，不能把当前 reward 或 privileged 通道造成的增量称 RGB 增量。
3. **真实控制相关**：同一冻结有限动作／后续控制／时间窗下，事件两端存在有实用代价的动作排序差，例如同初态两事件的 δ-optimal 集合不相交。仅 reward 降低、正负姿态不同、可识别 C 或高 KL 都不够。事件符号不是正确动作标签，标签必须来自真实控制后果。
4. **表征可用性独立验**：q/p 实际接口在新预定 readout／直接因果行为对象下分别评估；同 h 下 p 无法接收 C 是设计条件，q 有变化不证明正确编码。当前 actor 与未来可学习性分开；任一路实际阳性都要有独立留出和函数类局限。

前三项失败时，应停止这个事件对象，不继续模型辨别或压缩学习。第四项失败限于其诊断器，不直接否定图像或所有学习路线。

## 5. 单 transition torque 的合法性与反例

目前提出的物理候选是绕世界 y 轴的预定有界躯干力矩，在 `p−1→p` 一次正常控制步中施加；施加后恢复原外力字段，而不是盲目全部清零。factory qpos0 下该轴与侧向投影变化有关，但它不等于任意自然姿态的 body-local pitch，且具有相机深度轴分量。控制步／子步、外力单位和相机参数已有源码／元数据事实，见 [DL_CUE_PREFLIGHT.md](DL_CUE_PREFLIGHT.md)；幅度、event 分配、状态范围、动作集合、可辨／后果门与硬预算仍**未冻结**。

必须从可信 p−1 snapshot 执行原 raw→applied 动作，得到相同 p clock，并与上述实际 p 前 carry 对齐。只使用 p snapshot 再额外一步而仍拿 p 前 carry是不合法的对齐。actuator filter 随原控制自然演进，不能要求其保持 p−1 activation；有界 wrench 合法也不保证接触、姿态或相机投影仍在训练支持内。

最强反例与停止理由包括：

| 反例 | 不能推出的结论／需要的证据 |
| --- | --- |
| 一步主要改变速度，姿态像素没有可辨改变 | 不可预知状态变化不等于当前 RGB 有新线索；单帧不可辨就停止，不增力／延窗求可见 |
| camera tracking 消除平移，或姿态被遮挡 | 真物理差异不保证视觉可获取，须实际相机与识别审查 |
| 正负事件的姿态变化可见，但近正立 reward／有限动作需求对称 | cue 可识别不等于决策需要，须真实排序／代价，不凭符号猜控制 |
| 世界外力虽有界，却产生训练未见状态／动力学 | 可以是明确的受控扰动范围，不能声称 clean 常规轨迹的验证或 OOD 已排除 |
| q 对事件响应且 D/K 大，但动作／task readout错误 | 响应不等于有用新信息；要保留“错误依赖”反例 |
| q 接口可学，但当前 actor不利用，D低 | 当前 Dt gate 可漏保；actor阳性不是未来学习必要门，K乘子也修不了任何仍须 D 非零的形式 |

合法状态与训练支持是两个条件。不能以“MuJoCo 可以运行”证明 in-distribution，也不能以训练支持稀薄自动否定一个明确限定的鲁棒性对象。若要支持原 clean 目标，仍需新的自然事件或明确训练覆盖；受控挑战不能替代它。

本稿不建议目前直接冻结 torque 幅度或启动。缺失的是可辨线索与真实动作需求的物理／视觉可行性论证，而不是更多 D/K 数值。静态矩形遮挡可作为观测可获取性辅助；它既不建立独立历史事件，也不提供真实状态下的新决策需要。已有 gray-body 保留轮廓／姿态／影子，不能被重命名为完整 cue 移除。

## 6. 与原 DtLatch 目标的最小证据链

本项目目标仍为辨别高 D 的不同成因，适当保护 posterior并最终提高性能。一个有限 cue 对象阳性不足以完成这条链。

| 证据环节 | 必须回答的问题 | 不能替代它的证据 |
| --- | --- | --- |
| 外部对象与信息来源 | 历史不可预知、可观测线索是否真正改变有限决策？ | D/K 高、低 reward、姿态差或任意随机冲击 |
| 表征／当前行为／未来可学性 | q 是否保留可获取线索，现 actor是否利用，或独立学习器是否可利用？ | q/p 值不同、固定 head漂移、微小 MSE改善 |
| 第二信号相对 D 的增量 | 在任务事件和 task-preserving nuisance上，rawK或新的支持信号是否提供超出同容量 D-only 的辨别？ | K与D相关、K=g(D) 的额外非线性basis、事件标签来自信号本身 |
| 真正活跃压缩机制 | raw rep在原 free-nats之上，正常shared-loss是否使可学task信息退化，有限保护是否改善？ | 只改posterior logits、inactive KL loss数值变化、局部梯度恒等式 |
| 选择与替代解释 | 相同总强度、有效对应关系、reward-only、背景/OOD/actor支持是否解释改善？ | 调 rho/alpha、交换相同权重、未经校准S/P/W |
| 后续学习与性能 | 预定未见对象、有限学习，再正式多seed性能是否提高且成本可接受？ | 当前冻结actor即时正号、工程exit0、短预算单任务结果 |

信号定义须先冻结：当前 r1 D 是同 h、categorical mode的条件 Gaussian 对称 KL／actiondim，既不是实际裁剪执行动作的差异，也不能直接使用真实 latent边际的 data-processing界。rawK虽在 Dreamer 内现成，但和 D共享q/p，不能称统计独立真值。mode／采样／clipping贡献须分别验收，不能把旧reward支持失败对象默默复活为新有效代理。

目标事件与 nuisance应有独立外部定义；高 D层、第二信号／readout选择、比较容量和停止规则须在新检验前冻结。若目标没有高 D，不挑事件求大 D，应记录 Dt 的漏检范围。若两种事件都使 D/K大，K不能区分它们的反例保留，不再放大强度。

学习路线的最小因果要求是独立可学task信息与 active rep作用，**不是当前 frozen q actor必须已有收益**。若前置成立，另立正常完整shared-loss的少量更新比较，固定数据／优化器／随机起点，各条件重新构建history并重新拟合同容量readout。还须后续actor学习证据才能外推性能。步数、保护强度、任务数据和S/P/W目前未定，不由本稿启动。

## 7. 推荐下一决定与边界

首选下一实际准备是**probe检测范围与新对象必要性的只读／纯合成规范审查**；不读真实blind，不重拟合旧r1，不做新的physics或model调用。若规范不足以决定下一对象，应明确记录缺失的 cue可辨、动作需要、训练支持或估计器证据，不宣布方法准备就绪。

new nested probe与合法随机化cue是两个替代问题，应由root在审查后选择一个最小有限版本，固定唯一主量、全部候选、数据分割与硬停止。任何新结果都保留旧失败。即便某一路探索支持，也只能选择下一条证据链，不直接授权gate、短训练或消耗全部blind。

草案作者仅做源码／文档只读讨论。root 后续已审阅并归档本稿及独立 factory-model 元数据核查；后者仅模型构造与数值查询，没有真实数据、reset／transition／render／Dreamer／GPU，未修改算法或原统计门。承接者继续当前完整授权聊天，先补齐纯合成规范；不自动创建或发送其他 chat。当前 actor 阳性不作为所有后续学习路线的必要门，完整方法目标仍未完成。
